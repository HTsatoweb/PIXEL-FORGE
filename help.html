01はじめての操作：最初の1枚

  1. ホーム画面の「新しい作品」を押します。編集画面からも上の「新規」で作成できます。
  2. サイズプリセットを選びます。迷ったら「横長 1920×1080」か「カスタム」のままで大丈夫です。
  3. 右側の「ペン・筆の種類」からGペン、鉛筆、水彩などを選びます。
  4. 上部の「サイズ」「不透明度」を調整し、中央のキャンバスに描きます。
  5. Ctrl + S で `.pforge` プロジェクトを保存します。
最初のおすすめ：Gペンを選び、サイズ5〜7px、筆圧サイズONで試してみましょう。マウスでも描けますが、筆圧は対応ペン・タブレットが必要です。

02画面の見方

左：ツールバー

ブラシ、消しゴム、線、図形、塗りつぶし、スポイト、文字、移動、変形などを切り替えます。

上：コンテキストバー

サイズ、不透明度、安定化、グラデーション、対称描画、ズームを調整します。

中央：キャンバス

作品を描く場所です。ホイールでズーム、Space＋ドラッグで表示位置を移動できます。

右：設定パネル

色、ブラシ、紙質、テキスト、アニメーション、レイヤー、書き出しを設定します。

右上の「パネル」で設定エリアを表示／非表示にできます。各パネル見出しを押すと折りたためます。設定検索欄に「筆圧」「水彩」「レイヤー」などを入力すると該当項目へ移動します。

03ペン・画材の選び方

右側の「ANALOG BRUSH LIBRARY」で画材を選びます。検索欄、カテゴリ、ワンタッチ画材セット、お気に入りを使うと目的の画材を見つけやすくなります。

Gペン・丸ペン・ミリペン

漫画線や輪郭に。Gペンは筆圧の強弱、丸ペンは細線、ミリペンは均一な線に向いています。

鉛筆・色鉛筆

ラフ、スケッチ、塗り重ねに。紙質や紙目の強さを上げると質感が出ます。

水彩・油彩・アクリル

水分・拡散・顔料・粒状化や、ブラシの硬さ・流量を調整します。

エアブラシ・スプレー

柔らかい陰影や粒子表現に。エアブラシは柔らかな塗り、スプレーは散布・粒子の表現に使います。

Edgeで白い選択窓が出る問題への対策

v11以降では「ペン・筆の種類」の選択をアプリ独自のダークテーマ・スクロールリストに変更しました。候補一覧は画面内に固定表示され、選択後は既存ブラシ設定へ同期します。元の選択要素も内部に残してあるため、既存の画材処理・設定保存はそのまま利用します。

  1. 「ペン・筆の種類」の欄を押します。
  2. 一覧を上下にスクロールします。ホイール、タッチ、スクロールバーに対応します。
  3. 画材名を押すと選択され、一覧が閉じます。
  4. キーボードでは矢印キーで移動、Enterで決定、Escで閉じます。
カテゴリや検索で候補が絞られているときは、表示対象だけが一覧に並びます。目的の画材が見つからない場合はカテゴリを「すべての画材」に戻し、検索欄を消してください。

04筆圧・ペンタブレットを使う

Wacom、Huion、XP-Penなどの入力は、ブラウザが公開するPointer Eventsを通して受け取ります。メーカー独自機能や筆圧が出ない場合は、Windows側のドライバー設定も確認してください。

  • 「DEVICE & PERFORMANCE」で入力デバイスと筆圧表示を確認します。
  • 「ペン傾きで太さを変える」を有効にすると、対応デバイスの傾き情報を使います。
  • 「筆圧カーブ」で軽い入力／強い入力への反応を調整します。
  • 「線のなめらかさ」「追従補間」「入り抜き」は描き味を見ながら少しずつ調整します。
  • 画面が重いときは「軽量モード」または「高速優先」を選びます。
Edgeのサイト権限で入力がブロックされていないこと、ペンタブレットのドライバーが最新であること、他の描画アプリがペン入力を占有していないことも確認してください。

05レイヤー・下敷き

レイヤーパネルの「＋ レイヤー」で追加、「複製」で複製、「削除」で削除します。上下ボタンで順序を変更し、「結合」で下のレイヤーとまとめます。

  • 目のアイコンで表示／非表示を切り替えます。
  • 「レイヤー不透明度」で選択中レイヤーの濃さを変えます。
  • 合成モードは通常、乗算、スクリーン、オーバーレイなどから選べます。
  • 参照写真は下敷きとして読み込み、表示・不透明度・位置を調整できます。
レイヤーの結合や削除をする前に、必要なら別名でプロジェクト保存をしてください。

06編集・変形・効果

図形・直線

左ツールから直線、四角形、楕円、三角形、星、多角形、矢印、ベジェ曲線を選びます。

塗りつぶし

許容値、隣接判定、結合画像参照、不透明度、境界フェザーを調整できます。

変形

Vで変形ツール。ドラッグ移動、上側ハンドルで回転、角で拡大縮小。Shiftで縦横比固定。

対称描画

上部の対称メニューから左右、上下、4分割、放射8などを選びます。

フィルター

モノクロ、セピア、ぼかし、ピクセル化、ノイズ、シャープ、輪郭抽出など。

テキスト

文字ツールでキャンバスにテキストレイヤーを作り、フォント、太さ、配置を調整します。

07アニメーション

ANIMATIONパネルでフレームを追加・複製・削除し、選択フレームを切り替えます。FPSで再生速度を設定し、オニオンスキンで前後の絵を薄く表示できます。

  1. 最初のフレームに絵を描きます。
  2. 「フレーム追加」または「複製」で次のコマを作ります。
  3. 少しずつ絵を変え、フレームを追加します。
  4. 再生ボタンで動きを確認し、必要に応じてFPSを調整します。
  5. アニメーション書き出しからWebMとして保存します。
フレーム数やキャンバス寸法が大きいほどメモリを使います。書き出し前にプロジェクトを保存しておくと安心です。

08保存・読み込み

プロジェクト保存（推奨）

「保存」または Ctrl + S で`.pforge`形式に保存します。v13はv10のversion 5データ構造を引き継ぎ、レイヤー画素、順序、表示状態、合成モード、画材設定、ブラシプロファイル、参照写真、アニメーション情報などを保存します。

自動保存

ブラウザのIndexedDBに編集状態を自動保存します。同じブラウザ・同じサイトのデータを消去すると復元できなくなるため、大切な作品は`.pforge`として別途保存してください。

旧版プロジェクト

v8/v9の`.pforge` version 3/4を読み込む互換性を維持しています。Undo / Redoの履歴スタック自体はプロジェクト保存対象外です。

11Edge・ブラウザ対応について

ブラウザのネイティブ選択メニューはOSやブラウザのテーマ設定により、ページ側のCSSが一部反映されないことがあります。v11以降では画材一覧を独自UIで描画することで、Edgeでも白い候補ウィンドウに頼らないようにしています。

  • 画材一覧は独自のスクロール領域で表示します。
  • 候補一覧はウィンドウの外へはみ出さないよう上下位置を調整します。
  • マウスホイール、スクロールバー、タッチスクロールに対応します。
  • フォーカス、矢印キー、Enter、Escに対応します。
  • 元の画材IDと値を維持し、アプリのブラシ切替イベントへ連携します。
  • ほかの標準選択欄にもダーク配色指定を追加しました。ただしOSの強制ハイコントラスト設定など一部環境では、ブラウザ標準表示が優先される場合があります。

12困ったとき・トラブル対策

画材の一覧が開かない／表示されない

画材欄を再度押してみてください。検索欄を空にし、カテゴリを「すべての画材」に戻します。それでも改善しない場合はページを再読み込みしてください。保存済みプロジェクトがあることを確認してから再読み込みしてください。

描画できない・ペンが反応しない

ブラシツールを選択し、ロックされていないレイヤーがあるか確認します。ペンタブレットのドライバー、Windows Ink設定、ブラウザ権限を確認し、マウスでも描画できるか試してください。

筆圧が反映されない

ブラウザが筆圧イベントを受け取れている必要があります。デバイス確認パネルを見て、タブレットドライバーとWindows側の筆圧設定を確認してください。ブラウザによって取得できるペン情報に差があります。

動作が重い・メモリが足りない

軽量モードまたは高速優先に切り替え、キャンバスサイズ・レイヤー数・アニメーションフレーム数を抑えてください。作業中の作品を先に保存してください。

自動保存から復元できない

別のブラウザ・別のプロファイル・プライベートウィンドウでは保存領域が別です。ブラウザのサイトデータを削除した場合も自動保存は消えます。外部ファイルの`.pforge`をバックアップとして使ってください。

オフラインでも利用できますか？

一度ローカルサーバーまたはWeb配信で読み込んだ後、Service Workerのキャッシュが有効なら、同じオリジン内のファイルをオフラインで開ける場合があります。初回読み込みやキャッシュ更新にはネットワークが必要です。

修復やブラウザのサイトデータ削除を行う前に、必ず`.pforge`を別の場所へ保存してください。

16パラパラ漫画・フレームアニメーション

右側の「ANIMATION / フレームアニメーション」でフレームを作ります。空白フレームを追加するか、現在のフレームを複製して少しずつ絵を変えていきます。

  • フレーム選択：下部タイムラインのサムネイルをクリック。
  • 順序変更：「← 順序」「順序 →」で選択フレームを移動。
  • 再生：FPSを1〜60で設定し、ループ・1回・往復を選択。
  • オニオンスキン：前後フレームを薄く重ねて動きを確認。
  • 書き出し：WebM動画、PNG連番ZIP、スプライトシートPNGに対応。

再生中は誤操作を避けるためキャンバス描画入力を停止します。フレーム切替時は非同期読込の競合を避けます。

17リアルで滑らかな描画の調整

筆圧サイズ・筆圧不透明度・傾き・線補正・微振動補正・速度応答・入り抜き・紙との相互作用を組み合わせます。描き足し時のプレビュー差を抑えたい場合はBRUSH LABの「PRO STROKE ENGINE」で「高精度・確定後と同じ合成」を選びます。

  • 筆圧の最小／最大：弱い入力のノイズや最大反応を調整。
  • 筆圧変化の安定化：筆圧の揺れを滑らかにし、強弱が急に変わるのを抑制。
  • サンプル密度：入力点を細かく残すか、軽さを優先するかを調整。
  • 曲線補間：線の追従と輪郭の滑らかさを調整。
  • 低遅延：負荷が気になるときは低遅延プレビューへ切り替え。
設定を一度に大きく動かさず、同じ線を描き比べると自分の入力機器に合った値を見つけやすくなります。

18全ブラシの微細挙動 · v17.0 ULTRA BRUSH MICRO-DYNAMICS

v17.0では、v16までの描画・レイヤー・アニメーション・保存機能を残し、ブラシの基本リボン形状、筆圧、筆先角度、毛束の挙動を細かく調整できるようにしています。新設定はブラシプロファイルと作品メタデータに保存されます。

全ブラシ共通の線の制御

  • 筆圧線幅ゲイン：筆圧カーブに対して線幅変化を強める／弱める。
  • 筆先角度モード：固定角度、線の進行方向、対応スタイラスの傾き、両方の組み合わせ。
  • 微細な線幅変化：位置とストロークIDに基づく決定的な微小揺らぎ・周期変化。再描画時にランダムに明滅しないよう同じストロークでは同じ変化を使う。
  • テーパー指数：入り抜きカーブの強さを調整。
  • 傾き反応：傾き対応ペンで有効にした場合だけ適用し、指やマウスに架空の傾きを加えない。

毛束・筆毛の挙動

  • 開き：筆圧による毛束の広がりを調整。
  • 個体差：毛先の長さ、太さ、濃さを毛ごとに安定した値で変化。
  • まとまり・水分：毛束のクランプと濡れた毛のまとまりを調整。
  • 曲がり・遅れ：曲率や移動速度に対する毛先の逃げ・追従遅れを調整。
  • うねり：毛筋に細かな連続変化を追加。
  • 毛先パスはストロークごとに決定的に生成し、フレーム更新のたびに形がランダム変化しないようにする。

顔料・輪郭

  • 顔料の初期量・濃度低下、ストロークの乾燥感、濡れ縁の広がり、下色を拾う半径、筆跡内部テクスチャの粗さを個別に設定。
  • 下色拾いは対応する油彩・不透明画材の描画前サンプルから計算。
  • これらはCanvasによるデジタル画材モデルであり、実際の液体・毛の物理シミュレーションや実物紙のスキャンではありません。

追加ブラシ

フィルバート、刷毛、モップ水彩、レーキ、ダガー、ブレンダー、ドライファン、ソフトカーボン、ワックスクレヨン、黒鉛粉、幅広淡墨筆を追加。v16の68種類から79種類へ拡張しました。

微細設定は「BRUSH LAB → ULTRA MICRO-DYNAMICS」にあります。高い毛束密度・大きなブラシサイズ・高精細モードの組み合わせは端末負荷が上がるため、スマホでは毛束密度や描画品質を下げてください。

過去版v17の個別資料はこの配布パッケージには含まれていません。現行の機能概要は 機能一覧、今回の変更・検証は v36.0変更履歴 と v36.0検証結果 を参照してください。

19ホームと作品ライブラリ · v18.0

v18では起動時の画面を作品ホームに変更しました。「新しい作品」から作成した絵は、作品ID・サムネイル・作品名・作成日・最終編集日と一緒に、このブラウザのライブラリへ自動登録されます。

  • 再編集：作品カードをタップ／クリックすると、作品データを開いて編集画面へ移動。
  • 検索・並べ替え：作品名検索、最終編集日順、作成日順、名前順。
  • 管理：名前変更、複製、削除。削除確認は全体設定で切り替え。
  • 自動保存：編集内容を指定した間隔で IndexedDB に保存。レイヤー構成も含めて保存。
  • 旧版自動保存：v17以前の `autosave.data` を同じブラウザで見つけると、初回起動時にライブラリ用レコードへコピーして作品カードにします。
  • 旧 `.pforge`：ホームの「既存作品を開く」から選択すると、内容を維持してライブラリへ追加。
作品ライブラリはブラウザ内に保存され、クラウド同期はありません。ブラウザのデータ消去や端末変更に備え、重要な作品は `.pforge` ファイルでもバックアップしてください。

古いプロジェクトを開く前に、元ファイルを別の場所へバックアップしてください。現行の対応範囲と検証状況は README と v36.0検証結果 に記載しています。

20スマホ操作・スポイト・発光色 · v18.0

スマホ画面下のクイックツールに「スポイト」「塗りつぶし」「指先混色」「手のひら」を配置しました。スポイトを選び、キャンバス上の色をタップすると前景色へ反映されます。

タッチ操作を「ペンのみ」または「移動のみ」に設定していると、スポイト・塗りつぶし・テキストのタップ操作まで早期returnで遮断される分岐を修正しています。2本指ピンチなどのジェスチャー経路は維持しています。

色パレットの拡張

  • ゴールド・金属24色：アンティークゴールド、真鍮、メタリックゴールド、シャンパンゴールド、ローズゴールド、プラチナなど。
  • ネオン・発光20色：レーザーレッド、ネオンライム、シアン、ブルー、バイオレット、マゼンタなど。
  • 宝石16色、パステル12色、色相と明度から生成する160色を追加。基本色を含め約248色から検索・カテゴリ選択できます。

アプリ全体設定
