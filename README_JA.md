# PIXEL FORGE STUDIO v18.0

作品ライブラリ・モバイル操作・拡張カラー・全体設定を搭載したブラウザ向けデジタルペイントスタジオです。

## 起動

- Windows：`run_local_server.bat` が含まれる配布版では、それを実行して表示された localhost URL をブラウザで開きます。
- または、このフォルダーで Python 3 を使い `python -m http.server 8000` を実行して、`http://localhost:8000/` を開きます。
- `file://` でも基本描画は開けますが、Service Worker やアプリインストール機能は HTTPS／localhost が必要です。

## v18の主な機能

- ホーム画面＋作品ライブラリ（サムネイル、作品名、作成日、最終編集日、検索、並べ替え）。
- 新規作品の自動登録、自動保存、再編集、名前変更、複製、削除。
- スマホ用クイックツール（スポイト、塗りつぶし、指先混色、手のひら）。
- 金属・ゴールド24色、ネオン20色、宝石16色、パステル12色、生成色160色を含む約248色パレット。
- テーマ、UI倍率、自動保存間隔、初期キャンバス寸法・背景・DPI、作品カード密度、スマホタッチボタン、削除確認、低モーション設定。
- PWA Manifest／Service Worker対応。対応ブラウザではインストール可能。

## 既存機能

既存の描画、ブラシプリセット、画材・紙質、筆圧・傾き・毛束モデル、水彩・油彩近似、レイヤー、Undo/Redo、テキスト、参照画像、変形、フィルター、アニメーション、画像書き出し、PSD互換モジュール、OpenRaster、`.pforge` の読み書きを維持しています。

## 作品の移行

- v17以前の自動保存データは、同じブラウザ・同じ端末で v18 を開くとライブラリへ移行します。
- `.pforge` ファイルはホームの「既存作品を開く」から読み込めます。
- 作品形式 `PIXEL_FORGE_PROJECT` version 5 はそのままです。
- 移行の詳細は `MIGRATION_v18_JA.md` を参照してください。

## 大切な作品のバックアップ

作品ライブラリは端末内のブラウザ IndexedDB に保存され、クラウド同期はありません。ブラウザデータ消去・端末故障・別端末への移動に備え、重要な作品は「保存」で `.pforge` ファイルを作成し、別の場所にも保管してください。

## 検証

- `python verify_v18.py`：HTML ID・旧ID保持・保存形式・モバイルタップ分岐・パレット・JavaScript構文を検証。
- `node brush_dynamics_smoke_v17.cjs`：既存ブラシ幾何スモークテスト。
- `FEATURES_v18_JA.md`：機能・操作・回帰チェックの一覧。
- `EDGE_CHECKLIST_v18_JA.md`：PC・スマホ実機チェック。
- `TEST_RESULTS_v18_JA.md`：今回実施した確認と未実施項目。

## 画材シミュレーションの範囲

水彩・油彩・毛束・紙質の表現はCanvasによるデジタル近似です。実際の流体力学や毛一本の物理解析ではありません。筆圧と傾きはOS・ブラウザ・対応ペンに依存します。
