# PIXEL FORGE STUDIO v31.0

スマホ・PCのエディタ上部操作列を左寄せに固定し、UIのドラッグ配置編集、ボタン順変更、虹色ブラシ、近未来モーションを追加した更新版です。v30までの描画・保存・PSD・レイヤー等の機能は維持しています。

## 起動
1. ZIPを新しいフォルダへ展開します。
2. Windowsは `run_local_server.bat`、macOS/Linuxは `run_local_server.sh` を起動します。
3. PCでは表示されたlocalhost URLを開きます。スマホからは同じWi-Fi上のPCのLAN IPとポートを開きます。
4. Service Worker利用にはHTTPSまたはlocalhostが必要です。

## スマホ上部ボタン
エディタ上部はロゴのすぐ右から、コマンド・ホーム・設定・新規・保存の順に左詰め表示します。380px以下ではロゴとボタンをさらに圧縮します。重複操作のヘルプ／パネルボタンは小画面で隠し、必要な設定は歯車または下部クイックツールから開けます。

## UIの位置をカスタマイズ
1. エディタ上部の歯車から「アプリ全体設定」を開きます。
2. 「エディタUIの配置カスタマイズ」→「配置をカスタマイズ」を押します。
3. 各パネルに出る⠿をドラッグすると位置を変更できます。
4. 上部ボタン・下部クイックツールをドラッグすると順番を変更できます。
5. 画面上部の「完了」を押すと、その端末サイズの配置を保存します。
6. 初期化は設定内の「初期配置に戻す」を使用します。

配置はスマホ用とPC用で別々に保存されます。ストレージを利用できない環境では保存に失敗することがあります。

## 虹色ブラシ
編集画面右側のブラシ設定で「🌈 虹色ブラシ」を選択します。既存の滑らかな線描画を利用し、連続した色相グラデーションで描きます。

## 保存
保存ボタンは進捗オーバーレイを表示しながら、アプリ内ライブラリと `.pforge` ファイルへ保存します。ホームへ戻る際も未保存作品を保護し、ライブラリ保存に失敗した場合は外部バックアップを試します。大切な作品は `.pforge` ファイルも別途保管してください。

## サイトキャッシュを0にする
アプリ全体設定 → サイトキャッシュ管理 →「キャッシュを0にする」。PIXEL FORGE専用Cache StorageとService Workerを削除し、再有効化するまで自動登録を停止します。IndexedDBの作品・ブラシ設定は削除対象ではありません。ブラウザ内部のHTTPキャッシュはWebアプリから直接削除できません。

静的検査結果は `TEST_RESULTS_v31_JA.md`、100項目の最終確認シートは `MOBILE_REPAIR_CHECKLIST_100_JA.md` と `V31_SUPPLEMENTAL_CHECKLIST_10_JA.md` を参照してください。実機ブラウザでのドラッグ・描画・保存テストは別途必要です。
