# PIXEL FORGE STUDIO WEB v16.0

## v16.0 追加内容

- スマホのアドレスバー開閉・画面回転・画面分割による描画領域変更中はキャンバスの再生成を保留し、ストローク終了後に中心位置を保って反映。
- 横向きスマホ・タッチタブレットも検出し、クイックツール・設定ドロワー・操作カテゴリへアクセス可能に。
- ペン使用中の指・手のひら誤入力を抑える設定、複数ポインターと2本指ジェスチャー終了処理を追加。
- 通常サイズのモバイル描画プレビューは原寸ドキュメント解像度を使い、確定後と同じ描画経路に統一。長い筆跡だけ表示範囲内プレビューへ制限。
- 表示フレームを裏バッファで合成してから一括反映し、途中の表示状態を抑制。
- 16種類のブラシを追加し、ブラシプリセットは合計68種類。
- 12種類の紙質を追加し、「なし」を含めて合計42種類。紙繊維の方向・紙目スケール・表面凹凸を調整可能。
- v15までの既存ツール、レイヤー、アニメーション、保存・書き出し、Edge向け選択UI、旧`.pforge`互換を維持。

## 品質・回帰チェック

`FEATURES_v16_JA.md`には100項目の確認一覧があります。内訳は16種の追加ブラシ・12種の追加紙質・39個の新しい詳細設定・33個の描画／端末挙動改善です。100個の完全に独立した物理エンジンという意味ではありません。

### 起動
1. ZIPを展開します。
2. `run_local_server.bat` を実行します（Python 3が必要です）。
3. 表示されたローカルURLをブラウザで開きます。
4. `help.html`にスマホ操作・紙質・ブラシのガイドがあります。

### 検査
`verify_v16.py`を実行すると、JavaScript構文、HTML ID重複、ローカル参照、Service Workerキャッシュ対象、100項目のチェック数を確認します（Node.jsがある場合はフレーム読込スモークテストも実施）。

### 紙質・素材について
紙の繊維・凹凸・粒子・吸収感はCanvasベースのデジタル質感シミュレーションです。実物の紙を撮影したテクスチャや物理的な顔料シミュレーションではありません。

## 既存バージョンから引き継いだ内容

- Edge / Chromiumで画材（Gペン・鉛筆・エアブラシ・スプレー等）を選ぶポップアップを、アプリ内スクロール式リストへ変更。白いネイティブ選択窓への依存を減らし、既存のブラシ状態・イベントへ同期します。
- 上部に閉じられるアップデート通知を追加。×で閉じた情報は同じバージョンでは再表示せず、次のバージョンでは新しく表示できます。
- `help.html` に独立した日本語の使い方サイトを追加。エディター右上の「？」または「ヘルプ」メニューから開けます。
- v14の描画中チカつき対策に加え、v16ではスマホ・タッチ端末の描き足しプレビュー、原子的フレーム合成、追加画材・紙質を強化。
- Service Workerキャッシュをv16.0へ更新。

### 起動・ガイド
1. ZIPを展開します。
2. `run_local_server.bat` を実行します。
3. エディター右上の「？」から使い方サイトを開けます。
4. `help.html` は単独で開いても閲覧できます。

### 検査
`verify_v16.py` を実行すると、JavaScript構文、HTML ID重複、ローカル参照、Service Workerキャッシュ対象、100項目チェック数を確認します（Node.jsがある場合は構文検査とフレーム読込スモークテストも実施）。

## v10の主目的：画材・設定・作品の完全保存

v9の全ファイル・全ツール・全パネル・筆跡エンジンを残したまま、プロジェクト保存と画材別プリセット管理を強化しました。

### `.pforge` に保存する内容
- 全レイヤーの画素データ（PNGデータURL、可逆）
- レイヤー名、順序、表示状態、不透明度、合成モード、文字レイヤー情報
- キャンバス寸法、DPI、背景、用紙、紙目強度
- 選択中のツール、色、ブラシサイズ、不透明度、硬さ、安定化、対称描画
- Gペン／鉛筆／水彩／油彩／マーカー等の全ブラシ設定値
- 筆圧プロファイル、速度応答、入り抜き、傾き感度、摩擦・追従補間
- 水彩の水分・拡散・吸収・粒状化・乾燥・濡れ縁の各設定
- 塗りつぶしの許容値、隣接判定、結合画像参照、不透明度、境界フェザー
- 書き出し倍率、品質、マット色、グラデーションなどの編集設定
- 参照写真（下敷き）の画像データ、表示、不透明度、倍率、位置
- アニメーションフレーム、選択フレーム、FPS、オニオンスキン
- アクティブレイヤー、ズーム、キャンバス位置、右パネルと各パネルの開閉状態
- お気に入り画材、画材別の個別プロファイル、自動記憶設定
- UI内の入力・選択・チェック項目の値（98個のフォームコントロールを検出）

プロジェクト保存とIndexedDB自動保存は同じ保存スナップショットを使います。保存形式は `PIXEL_FORGE_PROJECT` version 5 です。

### 旧版との互換性
- v8/v9で作成した `.pforge`（version 3/4）を読み込めます。
- v10ファイルには旧版向けの `brushSettings` も併記します。旧版アプリでも基本的なブラシ設定とレイヤーは読み込める場合がありますが、v10専用のフォーム状態や画材別プロファイルは旧版では復元されません。
- PSD / OpenRaster / PNG / JPG / WebP / WebM の既存機能は維持しています。PSDの互換範囲は標準的な8bit RGBピクセルレイヤー中心のままです。

## 画材ごとの設定を個別記憶

BRUSH LAB の「画材別の設定を完全保存」を使います。
1. 「ブラシを切り替えると設定を自動記憶・復元」をONにすると、現在の画材設定を切替時に記憶し、以前使った画材に戻した時に復元します。
2. 「現在の設定を保存」で、名前を付けて現在の画材の値を保存できます。
3. 「選択した設定を復元」で個別設定を適用します。
4. 「設定パックを書き出す／読み込む」で `.pfbrushes.json` を使って別PCや別プロジェクトへ共有できます。
5. 「削除」は選択中画材の個別設定だけを削除します。画材本体や既存プリセットは削除しません。

画材別プロファイルにはサイズ、濃度、硬さ、流量、散布、ブラシ角度、筆圧、入り抜き、紙との相互作用、質感、摩擦、追従補間、水彩設定などを保存します。

## 軽量性
- プロジェクトの設定情報は小さなJSONメタデータとしてレイヤー画像とは分離して保存します。
- ブラシプロファイルは必要な数値と関連コントロールのみ保存します。
- 既存のWorker水彩・塗りつぶし、Undoタイル履歴、描画品質切替、軽量モード、タブレットUIは維持しています。
- 自動保存は7秒間隔の既存方式を引き継ぎ、v10の完全設定スナップショットを保存します。

## 起動
1. ZIPを展開します。
2. `run_local_server.bat` を実行します（Python 3が必要）。
3. 開いたローカルページを使います。静的サイトへアップロードして使うこともできます。

## 保存上の注意
- `.pforge` はレイヤー画素と編集設定を保存しますが、Undo / Redo の履歴スタックそのものは保存しません。
- ブラシの質感はデジタル画材エンジンによる近似です。現実の顔料・毛先の完全な物理再現ではありません。
- PSDのスマートオブジェクト、調整レイヤー、全てのレイヤー効果などは完全互換の対象外です。


## v12.0 パラパラ漫画（フレームアニメーション）

- 「＋空白」で透明な新規フレーム、「複製」で現在の絵を複製します。
- タイムラインのサムネイルをクリックすると、そのフレームを編集できます。
- FPSは1〜60。ループ／1回再生／往復再生に対応します。
- オニオンスキンで前後フレームを色分け表示します。
- WebM、PNG連番ZIP、スプライトシートPNGとして書き出せます。
- 再生中は描画入力を一時ロックし、停止すると選択中フレームを編集できます。
- フレーム切替や再生は順番に処理し、読込が競合して表示が巻き戻る問題を防ぎます。再生中は既存レイヤーキャンバスを再利用し、フルサイズキャンバスの再確保を抑えます。

## 滑らかな描画

ペンのcoalesced pointer samplesを利用します。v14の高精度モードを引き継ぎ、v16では通常ストロークをドキュメント解像度でプレビューし、確定後と同じラスタ経路を使用します。大きなプレビュー領域ではメモリ上限を優先し、低遅延プレビューへ切り替えます。

### v12.0 フレームアニメーション・描画応答性の強化
- 再生を逐次処理へ変更し、非同期読込の競合と停止時の誤通知を抑制。
- 1〜60 FPS、ループ／1回／往復再生、サムネイル付きタイムライン、フレーム並べ替えに対応。
- 前後フレームを色分けするオニオンスキン、WebM／PNG連番ZIP／スプライトシートPNG書き出しを追加。
- 再生時は既存レイヤーキャンバスを再利用し、画像デコード結果をフレーム単位でキャッシュ。
- スタイラスの入力サンプルを活用しつつ、長いストロークのライブプレビュー点数を制限して再描画負荷を軽減。
- `.pforge`識別子とversion 5は維持し、旧プロジェクトの形式を変更しません。
- `runtime_smoke_v12.cjs`で画像キャッシュ、フレーム読込、古い非同期読込破棄、キャンバス再利用を検査します。

実機Edge・ペンタブレットの筆圧／傾き／描画体感は、この環境では検証できていません。スマホ・タブレット・ペンタブレットの最終確認には`EDGE_CHECKLIST_v16_JA.md`を利用してください。
