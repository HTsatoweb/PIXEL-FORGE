# PIXEL FORGE STUDIO v29.0

ローカル優先で動作するブラウザベースのデジタルペイントスタジオです。v29では既存機能を維持しながら、スマホ縦横・小型タブレットの操作入口、設定パネルの開閉、保存失敗時の自動バックアップ、ホーム移動時の作品保護、進捗表示を重点修正しました。

## 起動

- Windows：`run_local_server.bat` をダブルクリック
- macOS／Linux：ターミナルで `./run_local_server.sh`
- PC：`http://localhost:8000/`
- 同じWi-Fi内のスマホ：`http://PCのIPv4アドレス:8000/`

サーバーを起動した画面は閉じずに利用してください。スマホ側から開く際はPCと同じWi-Fiを使用します。ネットワーク設定やファイアウォールによっては、プライベートネットワークでの通信許可が必要です。

## スマホ操作

- 下部クイックドックを横へスワイプして全ツールへアクセス
- 専用の「保存」「ホーム」ボタンを配置
- 右パネルはスライド式で、背景タップと閉じるボタンで閉じられ、パネル内スクロールに対応
- 横向きスマホ・タッチタブレットでは上部バーに設定ボタンを残します
- VisualViewport・画面回転・セーフエリア・ソフトキーボードの変化を追従
- タップ、画面遷移、パネル、保存進捗のモーションを追加

## 保存

レイヤーのPNG変換を非同期化し、進捗％・レイヤー数・処理容量を表示します。IndexedDBが利用できなければ `.pforge` を書き出し、ホーム移動前も同じバックアップを試します。バックアップまで失敗した場合はホーム移動を止め、編集画面に作品を残します。端末のメモリや保存容量によっては、大きな作品で時間がかかる場合があります。重要な作品は `.pforge` ファイルも別途保管してください。
