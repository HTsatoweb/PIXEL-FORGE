# PIXEL FORGE STUDIO v20.0

ブラウザで動作するローカル優先のデジタルペイントスタジオです。v20ではPCとスマホのホーム表示を分け、スマホから作品作成・読込・一覧管理へアクセスしやすくしました。

## 起動

Windowsでは `run_local_server.bat` を実行し、`http://localhost:8000/` を開いてください。Service Workerとローカルファイル読込を安定させるため、`file://` 直開きよりlocalhostでの起動を推奨します。

## v20のホーム

- PC：従来の横長ヘッダー・広いライブラリを使用。
- スマホ：専用ヘッダー・クイック作成・作品読込・作品数表示・下部固定バーを使用。
- 画面幅／タッチ環境に応じて自動で切り替わります。
- 作品ライブラリと編集処理はPC・スマホで共通です。

## 既存機能

ブラシ・筆圧・傾き・画材設定・レイヤー・変形・塗りつぶし・スポイト・アニメーション・タイムライン・自動保存・`.pforge`・PSD互換・画像書き出し・作品検索／並べ替え／複製／名前変更／削除を維持しています。v19の複数選択・一括削除も維持しています。

## 保存について

作品ライブラリはこのブラウザのIndexedDBに保存されます。端末移行・ブラウザデータ消去に備え、重要な作品は `.pforge` でバックアップしてください。
