# PIXEL FORGE STUDIO v27.0

ローカル優先で動作するブラウザベースのデジタルペイントスタジオです。v27では既存の描画機能を維持しながら、保存・自動保存・ホーム操作の不具合修正、PC／スマホ共通の操作接続、ボタンと画面遷移のモーション、参照ファイル検査を追加しました。

## 起動

- Windows：`run_local_server.bat` をダブルクリック
- macOS／Linux：ターミナルで `./run_local_server.sh`
- PC：`http://localhost:8000/`
- 同じWi-Fi内のスマホ：`http://PCのIPv4アドレス:8000/`

サーバーを起動した画面は閉じずに利用してください。スマホ側から開く際はPCと同じWi-Fiを使用します。ネットワーク設定やファイアウォールによっては、プライベートネットワークでの通信許可が必要です。

## UIモーション

- ボタン押下時の短いフィードバックとホバー
- ツール、色スウォッチ、レイヤー、フレーム、作品カードごとの個別モーション
- ホーム画面と編集画面の遷移モーション
- 設定変更、パネル展開、ダイアログ、進捗表示の反応
- OSの `prefers-reduced-motion` とアプリ設定「動きを減らす」に対応

描画キャンバスや描画ポインター処理には装飾モーションを適用せず、描画入力を妨げない構成にしています。

## 維持している主要機能

ブラシ、鉛筆、水彩、油彩、筆圧・傾き、紙質、顔料、レイヤー、変形、塗りつぶし、スポイト、文字、フレームアニメーション、PNG／JPG／WebP／PSD／OpenRaster書き出し、作品ライブラリ、`.pforge`、`.pfsettings`、端末診断、モバイルUI。

PSD互換は標準的な8bit RGBピクセルレイヤーを対象とし、Photoshop固有のスマートオブジェクト・調整レイヤー等すべてを再現するものではありません。

## 設定と作品の保存

- `.pforge`：レイヤーや作品データを保存
- `.pfsettings`：筆・画材・UI・端末設定のバックアップ
- IndexedDB保存は完了後に読み戻し確認を行います。
- ブラウザが対応していれば保存先を選択して`.pforge`を保存できます。非対応時はダウンロードへ切り替えます。
- ライブラリ保存に失敗した場合も、可能な限り外部バックアップの書き出しを試します。

同じブラウザ・同じサイトのデータを消すと自動保存設定は削除される可能性があります。大切な作品と設定は、それぞれ外部にバックアップしてください。

## 配布ファイルの整理

起動に必要なHTML／CSS／JavaScript／Worker／アイコン／マニフェスト／起動スクリプト／ヘルプ／現行資料を残しています。

## 検証と制限

- `TEST_RESULTS_v27_JA.md`：v27の自動検査結果と制限
- `IMPROVEMENTS_v27_JA.md`：修正・強化内容
- `CHANGELOG_v27_JA.md`：変更履歴
- `EDGE_CHECKLIST_v25_JA.md`：Android／iPhone／PC実機チェック項目

v27ではJavaScript 9ファイル、CSS 4ファイル、HTML ID・固定ID参照・ローカル参照・Service Workerのキャッシュ対象を静的検査しました。Chromium headlessで実画面を取得する試みは実行環境内でタイムアウトしたため、実画面クリック、IndexedDB実保存、ファイルダウンロード、ペン入力、iPhone Safari／Android Chrome実機での合格は確認済みとはしていません。配布後はアプリ内「端末診断」の「作品保存テスト」と実際の`.pforge`保存・再読込を確認してください。
