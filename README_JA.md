# PIXEL FORGE STUDIO WEB v17.0 · ULTRA BRUSH MICRO-DYNAMICS

## v17.0の追加・改善

- ブラシプリセット：68種類 → 79種類（11種追加）。
- 全ブラシ共通の線幅モデル：筆圧ゲイン、筆先方向追従、ペン傾き、微細な線幅変化、入り抜きカーブ指数。
- 自然画材の毛束モデル：筆圧による開き、長さの個体差、毛束のまとまり、水分による凝集、曲率に沿う逃げ、速度による追従遅れ、毛筋のうねり。
- 顔料・輪郭モデル：顔料初期濃度、濃度低下、乾燥感、濡れ縁の広がり、下色拾い半径、内部テクスチャの粗さ。
- 新しい25個の詳細コントロールをプロジェクトとブラシプロファイルに接続。
- 旧プロジェクトに新しいキーがない場合の既定値補完と値の範囲正規化。
- 毛束の経路は既にリサンプルされたリボン点列を再利用し、毛ごとの再サンプリングを避ける。
- 毛先パス生成と描画命令を分離し、スタイル適用前の余分なstrokeを除去。
- 毛束の揺らぎはストロークIDから決まる決定的な値を使い、プレビュー中のフレームごとの乱数変動を避ける。

## 起動

`run_local_server.bat`を実行し、表示されたローカルURLをブラウザで開きます。Python 3が必要です。

## 品質確認

`python verify_v17.py`でHTML ID、既存ID、ブラシ数、紙質数、コントロールの接続、プロジェクト保存キー、Service Workerのローカル参照、JavaScript構文、フレーム読込スモークテスト、ブラシ幾何の数値テストを確認します。Node.jsが必要です。

120項目の一覧は機能・内部挙動・保存互換性・回帰確認を細分化したものです。120個の独立した物理シミュレーションを追加したという意味ではありません。

## 画材モデルの限界

毛束・顔料・水分・紙質の挙動はCanvasを使ったデジタル近似です。実際の毛一本の弾性や流体力学を解くフル物理シミュレーション、実物紙のスキャンではありません。スタイラスの筆圧・傾きの取得可否はOS・ブラウザ・ペン機器に依存します。

## 互換性

既存のプロジェクト形式識別子と既存のHTML IDを維持し、新しい設定キーは不足時に既定値で補完します。作品を更新する前に`.pforge`のバックアップを作成してください。
