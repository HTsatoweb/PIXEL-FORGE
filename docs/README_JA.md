# PIXEL FORGE STUDIO v49.0

PIXEL FORGE STUDIOは、ローカル環境で作品を編集するブラウザベースのデジタルペイントスタジオです。v49.0はv48.0を基準に、v44.0の実ファイルと比較して旧版由来の機能・操作・説明の欠落を確認し、短縮されていた説明を復元した保全版です。

## フォルダー構成・起動

- 起動: `run_local_server.bat` または `run_local_server.sh`
- メイン: `index.html`
- ヘルプ: `help.html`
- JavaScript: `js/`
- CSS: `css/`
- 画像: `assets/images/`
- Markdown資料: `docs/`
- Service Worker: `sw.js`（ルートスコープ維持のためルートに配置）
- データベース: `PixelForgeDB` version 3（既存スキーマを維持）
- 作品形式: `.pforge` / `PIXEL_FORGE_PROJECT` version 5

IndexedDB、Service Worker、ファイル入出力を安定して使うため、`file://`直開きではなくローカルサーバー経由で起動してください。重要な作品は `.pforge` と `.pfarchive` の両方でバックアップすることを推奨します。作品のブラウザ保存領域はオリジン（スキーム・ホスト・ポート）ごとに分かれます。

## 既存の画材・描画機能

- ブラシ設定: 画材ごとの自動保存、書き出し・読み込み、別画材への設定コピー。画材プロファイルは84項目のフォーム状態を記録します。
- 虹色: 曲線方向、横方向、縦方向、開始位相、逆方向、下色拾いに対応します。
- 指先混色: 選択レイヤーのみ／表示レイヤー全体を選べます。
- レイヤー、選択・変形、消しゴム、塗りつぶし、スポイト、対称描画、紙質・水彩・混色設定を含む各種ツールと設定を維持します。
- PSD互換、PNG/JPEG/WebP等の画像書き出し、作品保存・読込、アニメーションフレームの編集・再生・書き出しを引き継ぎます。個別形式の完全互換性は対応範囲・検査資料を参照してください。

## v36.0: STUDIO+ 追加ツール

エディター上部の `STUDIO+` から20カテゴリの追加ツールを開けます。選択マスク・素材生成・配色・レイヤー複製フィルターなどの追加機能は、同梱の `CHANGELOG_v36_JA.md` および `IMPROVEMENTS_v36_JA.md` に記載された実装範囲・制限に従います。

## v41.0: ホーム／エディター全体のUI整理

「☷ UI整理」から、ホームとエディターのUIをパーツ単位で表示・非表示にできます。

- **ホーム／エディター**: 整理する画面を選びます。
- **PC／スマホ**: 設定対象の端末レイアウトを選びます。現在と異なる端末の設定も編集できます。
- **制作モード**: 「はじめて」「イラスト」「アナログ画材」「写真加工」「デザイン」「ピクセルアート」「アニメーション」「上級者」ごとに表示設定を保存します。
- **一覧のチェック**: チェックを外すとそのUIだけ非表示にできます。チェックを戻すか「戻す」で個別復元できます。
- **画面上で直接整理**: 選択したUIの位置に「×」を出して、その場で隠せます。通常操作を行うときは直接整理を終了してください。
- **すっきり／集中／標準**: プリセットを切り替えます。プリセットで隠れた項目も一覧から戻せます。
- **このレイアウトを初期化**: 現在選択中の端末・画面・モードだけを標準に戻します。
- **隠したUIをすべて表示**: 現在選択中の設定プロファイルの非表示項目をすべて復元します。
- **見た目・操作感の細かい設定**: UI密度、全体スケール、パネル幅、ツールサイズ、間隔、角丸、ホーム列数、パネル左右位置、アニメーション、ツールヒント、ラベル表示を調整できます。

非表示は削除ではありません。作品データ、レイヤー、描画履歴、ブラシ、保存形式には変更を加えず、UI設定だけを `pf-ui-layout-studio-v41` に保存します。PCとスマホ、8つのエディターモードの設定は独立しています。表示設定スロット数はUI部品の表示カスタマイズの組み合わせ数であり、新規描画機能やブラシ数ではありません。

## v43.0: 省スペース・重なり防止UI

- モード別ワークベンチは折りたたみ時にPC約24px、スマホ約28pxへ圧縮します。表示を隠すだけで、モード専用の操作や設定は保持します。
- 展開時の操作列は横スクロールにまとめ、画面下／上方向へ大きく膨らむことを抑えます。PCでは縦ホイールでも横方向へ移動できます。
- PCの「UI整理」はステータスバー内の小型ボタンへ移動し、右側のブラシ設定やスライダーに重ならないようにします。ホーム／スマホでは従来の入口を維持します。
- 折りたたみ状態と非表示にした操作はモード別に保持します。

## v44.0: 全ウィンドウ共通管理・復旧

- 新しいキャンバス、描き方ガイド、アプリ設定、診断、インストール案内、コマンドパレット、STUDIO+、UI整理の閉じる動作を共通管理します。
- PCは閉じるボタン・背景クリック・Esc、スマホは閉じるボタン・背景タップ・ブラウザーの戻る操作に対応します。
- 最前面のウィンドウだけを閉じる優先順位、Tabフォーカス循環、開く前のボタンへのフォーカス復帰を扱います。
- スマホ設定パネルの閉じるボタンID不一致、ARIA状態、監視ループ、合成クリック再帰を修正した履歴を保持します。
- カスタム選択メニューを最前面レイヤーとして扱い、Esc／Tab／戻る操作に連携します。
- VisualViewport、画面回転、ソフトウェアキーボードを考慮したウィンドウ高さの補正を扱います。

v48.0では旧版の `window-manager-v44.js` を二重ロードせず、互換機能を引き継いだ拡張版 `window-manager-v45.js` を現行実行モジュールとして使用します。旧ファイル自体はアーカイブ内に残しています。両方を同時ロードするとイベントや監視処理が二重登録されるため、v45のみを有効にします。

## v47.0: 設定パネル閉じる処理

- PCで設定パネルを閉じた直後に、キャンバスのサイズ変更をきっかけにパネルが再表示される問題を修正しました。
- スマホの設定パネルを閉じる操作を、合成クリック方式から共通状態更新へ変更しました。
- 検索・一括展開／折りたたみ・閉じるボタンの配置、カテゴリータブのsticky位置を調整しました。
- `.pforge`の`PIXEL_FORGE_PROJECT` version 5、`PixelForgeDB` schema version 3は維持します。

## v48.0: ホーム／エディター／連携UIの強化センター

ホーム100項目、エディター200項目、連携・細部UI50項目を、カテゴリ検索・お気に入り・最近使った機能・ページ送りを備えた強化センターにまとめています。`Ctrl + Shift + P`（Macは`⌘ + Shift + P`）から開けます。

これら350項目は既存の描画・設定・保存・作品一覧・ワークフローへつなぐ操作ショートカット、プリセット、UI補助の合計です。350種類の独立した新規描画エンジンを意味するものではありません。項目の詳細と実装範囲は `FEATURE_ADDITIONS_v48_JA.md` を参照してください。

## v49.0: 旧版機能の保持・復元監査

- v44.0とv48.0のZIPを相対パス単位で比較し、v44由来の114ファイルがすべてv48にも存在することを確認しました。
- `index.html`の旧版ID 566件、`help.html`の旧版ID 30件はすべて現行に残っています。
- `app.js`の名前付き関数宣言312件は現行にもすべて残っています。現行側では新しい検証・復旧関数が追加されています。
- 旧READMEから省かれていたSTUDIO+、v41 UI整理、v43省スペースUI、v44ウィンドウ管理の説明を統合して復元しました。
- v48で`PF_APP_RELEASE`が47.0.0のままになっていたメタデータ不一致を49.0.0へ修正しました。作品形式version 5とIndexedDB schema version 3は変更していません。
