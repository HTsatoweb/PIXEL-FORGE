# PIXEL FORGE STUDIO v36.0

デジタルペイントスタジオ。HTMLはルートに残し、JS/CSS/画像/Markdownを用途別フォルダに整理しています。

- 起動: `run_local_server.bat` または `run_local_server.sh`
- メイン: `index.html`
- ヘルプ: `help.html`
- JavaScript: `js/`
- CSS: `css/`
- 画像: `assets/images/`
- Markdown資料: `docs/`
- Service Worker: `sw.js`（ルートスコープ維持のためルートに配置）
- データベース: `PixelForgeDB` version 3（既存スキーマを維持）
- ブラシ設定: 画材ごとの自動保存、書き出し・読み込み、別画材への設定コピー。画材プロファイルは84項目のフォーム状態を記録。
- 虹色: 曲線方向、横方向、縦方向、開始位相、逆方向、下色拾い
- 指先混色: 選択レイヤーのみ／表示レイヤー全体

重要な作品は `.pforge` と `.pfarchive` の両方でバックアップすることを推奨します。作品のブラウザ保存領域はオリジン（スキーム・ホスト・ポート）ごとに分かれます。

## v41.0：ホーム／エディター全体のUI整理

画面右下（スマートフォンでは下部ナビの上）にある **「☷ UI整理」** を開くと、ホームとエディターのUIをパーツ単位で表示・非表示にできます。

- **ホーム／エディター**：整理する画面を選びます。
- **PC／スマホ**：設定対象の端末レイアウトを選びます。現在と異なる端末の設定も編集できます。
- **制作モード**：エディターでは「はじめて」「イラスト」「アナログ画材」「写真加工」「デザイン」「ピクセルアート」「アニメーション」「上級者」ごとに表示設定を保存します。
- **一覧のチェック**：チェックを外すとそのUIだけ非表示になります。チェックを戻すか「戻す」で個別復元できます。
- **画面上で直接整理**：選択したUIの位置に「×」を出して、その場で隠せます。画面上のUIを通常操作したいときは、直接整理を終了してください。
- **すっきり／集中／標準**：プリセットを切り替えます。プリセットで隠れた項目も一覧から戻せます。
- **このレイアウトを初期化**：現在選択中の端末・画面・モードだけを標準に戻します。
- **隠したUIをすべて表示**：現在選択中の設定プロファイルの非表示項目をすべて復元します。
- **見た目・操作感の細かい設定**：UI密度、全体スケール、パネル幅、ツールサイズ、間隔、角丸、ホーム列数、パネル左右位置、アニメーション、ツールヒント、ラベル表示を調整できます。

非表示は削除ではありません。作品データ、レイヤー、描画履歴、ブラシ、保存形式には変更を加えず、UI設定だけを `pf-ui-layout-studio-v41` に保存します。PCとスマホ、8つのエディターモードの設定は独立しています。

表示設定スロット数は、実際に検出したUI部品数から算出した表示カスタマイズの組み合わせ数です。新規描画機能・ブラシ数を表す数ではありません。


## v43.0：省スペース・重なり防止UI

- モード別ワークベンチは折りたたみ時にPC約24px、スマホ約28pxへ圧縮。表示を隠すだけで、モード専用の操作や設定は保持します。
- 展開時の操作列は横スクロールにまとめ、モードによって画面下／上方向へ大きく膨らむことを抑制。PCでは縦ホイールでも横方向へ移動できます。
- PCの「UI整理」はステータスバー内の小型ボタンへ移動し、右側のブラシ設定やスライダーに重ならないように変更。ホーム／スマホでは従来のフローティング入口を維持します。
- 折りたたみ状態と非表示にした操作はモード別に保持。描画、作品データ、レイヤー、履歴、PSD／保存形式は変更しません。


## v45.0：全ウィンドウ共通管理・復旧

- 新しいキャンバス、描き方ガイド、アプリ設定、診断、インストール案内、コマンドパレット、Studio+、UI整理の閉じる動作を共通管理に統合。
- PCは閉じるボタン・背景クリック・Esc、スマホは閉じるボタン・背景タップ・ブラウザの戻る操作に対応。
- 最前面のウィンドウだけを閉じる優先順位、Tabフォーカス循環、開く前のボタンへのフォーカス復帰を追加。
- スマホ設定パネルの閉じるボタンID不一致を修正し、ARIA状態を同期。
- ウィンドウ監視の自己発火ループを防止し、無関係なDOM更新による不要な監視処理を削減。
- スマホ設定パネル閉鎖時の合成クリック再帰を排除。
- カスタム選択メニューを最前面レイヤーとして扱い、Esc／Tab／戻る操作に連携。
- モバイル履歴を単一マーカーで管理し、手動クローズ時の意図しないページ遷移を防止。
- VisualViewport、画面回転、ソフトウェアキーボードを考慮したウィンドウ高さの補正を追加。
- 端末・ブラウザ診断にウィンドウ要素、閉じる操作、重複ID、戻る操作、フォーカス制御の検査を追加。
- 描画エンジン、ブラシ処理、作品データ形式、PSD入出力、IndexedDBの既存スキーマは変更しません。

## v45.0 高速起動
