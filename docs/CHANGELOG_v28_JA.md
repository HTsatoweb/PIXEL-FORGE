# PIXEL FORGE STUDIO v28.0 — 修正履歴

## スマホUI・操作性

- 編集画面のクイックドックに専用の「保存」「ホーム」ボタンを追加。従来の上部ボタンやメニューも残しています。
- スマホ用ドックを1列の横スクロール式に統一し、幅の狭い画面でも全ツールへアクセスできる構造に整理。
- PC用の上部バー、左ツール、中央キャンバス、右設定パネルは維持し、スマホ用CSSは追加ファイルに分離。
- VisualViewportの幅・高さ・オフセットを反映し、アドレスバー、画面回転、ソフトキーボード表示時のレイアウト変化に追従。
- 設定パネルをスライド式ドロワーとして表示し、スクラブ領域、safe-area、ダイアログの表示サイズを調整。
- 320〜420px幅、スマホ横向き、タブレット幅のレイアウトを追加調整。

## 保存・パフォーマンス

- レイヤーのPNG化を `canvas.toBlob()` + `FileReader` による非同期処理へ変更。未対応時は従来の `toDataURL()` にフォールバック。
- 保存進捗バーにARIAのprogressbar属性を付与し、進捗率・処理容量・レイヤー数を表示。
- 保存中は描画領域への新規入力を一時停止し、保存スナップショットが編集中操作と競合しにくいように変更。
- サムネイル生成時にフルサイズ合成キャンバスを追加生成せず、320×200の縮小キャンバスへ直接レイヤーを合成。
- ホームへ移動する際の自動保存にも進捗表示を追加。ホーム画面への遷移は従来どおり即時。
- 端末診断へスマホ保存／ホームボタン、進捗バー、非同期PNG変換、モバイルドックの検査を追加。

## アニメーション・アクセシビリティ

- ボタン押下の短いスケール・バウンスモーションを追加。
- 設定パネル、画面切り替え、保存進捗カードに個別のトランジションを追加。
- `prefers-reduced-motion` を尊重し、動きを減らす設定時はアニメーションを抑制。
- タップターゲット、focus-visible、進捗バーの読み上げ情報を改善。

## 配布

- 新しいモバイルCSS／JSをService Workerの必須キャッシュ対象へ追加。
- キャッシュ名を `pixelforge-web-v28.0` へ更新し、古いキャッシュからの読み込みを防止。
- 既存のブラシ、レイヤー、PSD互換、アニメーションフレーム、描画エンジン、プロジェクト形式は変更していません。
