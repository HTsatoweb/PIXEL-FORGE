# v54.0 UIレビュー

## 優先して解消した問題
1. 下部ナビからUndo/Redoが隠れている：常設の2ボタンへ移動。
2. スマホUI整理FABが下部ナビを覆う：固定表示をやめ、ホーム／その他の中へ移動。
3. タップ処理が旧ドキュメント委譲に依存：captureフェーズの専用ルーターへ集約。
4. 履歴ボタンの使用可否が分からない：エンジンの履歴カウントに同期。
5. ドロワーを閉じにくい：閉じるボタン、背景タップ、Escape、OS戻る、見出し右スワイプに対応。親のスタッキングコンテキストを開いている間だけ前面化し、閉じるボタンが上部バーの裏へ隠れる問題も修正。

## PC
- 左ツール列と右設定欄を独立スクロール。
- 画面幅・画面高に応じてボタンと余白を調整。
- PCの背景テーマや編集機能は変更しない。

## 500項目について
「500個」は独立した500機能を意味するものとして水増しせず、実際に追加した操作とレイアウト変更のみを記録。今回のリリースは操作体系の基盤改善を中心とする。
