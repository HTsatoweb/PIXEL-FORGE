# PIXEL FORGE STUDIO v36.0 実装内容

## 追加ツールパネル

エディター上部の「STUDIO+」から20カテゴリの追加ツールを開けます。パネルはPC・狭幅画面に応じたレイアウトで表示し、OSの「視差効果を減らす／動きを減らす」設定では追加アニメーションを抑制します。

## 操作上の注意

- 自由形状選択は開始後にパネルを一時退避します。キャンバス上を囲み、下部のフローティングバーから内側・外側を適用してください。
- 選択マスクの画素適用後は、既存Undoで戻せます。大きいキャンバスは履歴メモリ上限により適用を拒否する場合があります。
- キャンバス拡張はUndo履歴をクリアします。大きな変更の前に通常保存またはスナップショットを作成してください。
- レイヤーフィルターは元レイヤーを非表示で残し、複製側に効果を反映します。
- SVGは外部参照等を除去してからラスター画像レイヤーに変換します。出力SVGはSVGソースとして保存されます。
- スナップショットは既存作品DBとは別のDBに保存されます。端末・ブラウザ・ポート・localhostのホスト名を変更した場合、保存領域も別になります。
- ストーリーボードとマクロ、補助キーフレームはブラウザ内ストレージに保存されます。ブラウザデータ消去前に作品本体を `.pforge` / `.pfarchive` でバックアップしてください。

## 動作範囲

v36は既存描画機能を維持しながら段階的な補助機能を追加する更新です。各パネルの説明にあるとおり、全機能が業務用DCCアプリ同等の完全な物理・GPU・AI・ベクター機能を実装したものではありません。未実装範囲を画面内に明記しています。
