# PIXEL FORGE STUDIO v36.0 変更履歴

## 新規追加

1. **画材物理コントロール** — 既存の水彩・顔料・紙応答エンジンへ、吸収・拡散・顔料濃度・粒状化と素材プリセットを接続。
2. **ブラシ先端ラボ** — 丸・平・斜め・扇・ナイフ・ソフトのプレビュー、扁平率・角度・スタンプ間隔・毛束数を既存ブラシ設定へ反映。
3. **自由形状選択・アルファマスク** — キャンバス上をドラッグして範囲を作り、内側または外側の画素を透明化。既存Undo/Redoを利用。
4. **レイヤー複製フィルター** — 元レイヤーを保持して非表示にし、複製へフィルターを適用。
5. **3点透視ガイド** — 3消失点と分割数・不透明度を調整する非破壊オーバーレイ。
6. **SVGユーティリティ** — プリミティブ作成、SVGテキストの安全化、画像レイヤーへの配置、SVGファイル出力。
7. **不透明度キーフレーム補助トラック** — レイヤー不透明度のキー登録・補間・ブラウザ内保存。
8. **OKLCHカラーピッカー** — OKLCH入力からsRGBへ変換し、既存の描画色へ適用。色調和候補も生成。
9. **写真加工の複製フィルター** — 元画像を残した比較用コピーを作成。
10. **ポーズ参考ビュー** — 関節値を調整できる簡易3D投影スケルトン。
11. **キャンバス拡張・ミニマップ** — 中央を維持して有限キャンバスを拡張し、全体プレビューから表示位置を移動。
12. **画材プリセット** — 水彩・インク・パステル・油彩キャンバス・和紙の設定を既存エンジンへ適用。
13. **プロシージャル素材生成** — 放射・ノイズ・ストライプ・格子・チェッカーを新規レイヤーとして生成。
14. **ストーリーボード** — 作品サムネイルとメモを最大20件、ブラウザ内へ保存。
15. **操作マクロ** — 許可リストに限定したボタン・コントロール操作の記録と再生。
16. **端末・描画診断** — Canvas 2Dベンチマーク、WebGL/OffscreenCanvas/Workerなどの対応状況を表示。
17. **作品スナップショット** — `PFStudioV36` という独立IndexedDBへ作品状態を最大10世代保存・復元。
18. **日本語文字配置** — 横書き・簡易縦書き・2桁数字の縦中横をレイヤー化。
19. **画像配色抽出** — 作品または画像から近似代表色を抽出。
20. **復旧・整合性診断** — 既存回帰テストと作品状態の確認をまとめて実行。

## 保護・互換性

- 既存の描画エンジンを置き換えず、限定された `PF_STUDIO_API` ブリッジから追加機能を接続。
- 既存の `PixelForgeDB` version 3 は変更しない。
- 既存の作品データ構造、ブラシ描画、レイヤー、フレームアニメーション、保存経路を維持。
- v36のスナップショット用DBは既存DBと分離。
- Service Workerのキャッシュ名をv36へ更新。
- キャンバス拡張は新しいレイヤーキャンバスをすべて確保してから切り替える方式にし、途中確保失敗時に一部レイヤーだけが変わることを防止。
- SVG読み込みはスクリプト・foreignObject・style要素・危険なイベント属性や外部参照を除去してから画像化。

## 制限事項

- 無限キャンバスではなく、既存の最大20メガピクセル制限内での有限拡張。
- 選択マスクは画素アルファへ適用する方式。編集可能な永続レイヤーマスクではない。
- 透視ガイドは補助表示のみ。消失点の自動検出・自動スナップはしない。
- SVGは配置時にラスター化される。編集可能なベジェパスオブジェクトではない。
- 追加キーフレームは不透明度のみで、既存のフレームアニメーションとは別トラック。
- ポーズビューは簡易スケルトン投影であり、人体解剖学に基づく高精細3Dマネキンではない。
- プロシージャル生成は固定パターンの簡易チェーンで、任意ノードを接続する汎用ノードエディターではない。
- 写真加工は複製レイヤーに既存フィルターを適用する方式で、周波数分離・AI修復・フォーカススタックは含まない。
- GPU機能は端末能力診断とCanvas 2D計測。ブラシ本体をWebGLへ移行していない。
- 日本語組版は簡易縦書き・縦中横。OpenType軸・ルビ・完全な禁則処理は含まない。
