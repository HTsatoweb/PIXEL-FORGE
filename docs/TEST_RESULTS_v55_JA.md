## 3. セキュリティ上の注意

- 既存のインラインスクリプト/スタイルと互換性を保つため、CSPでは `unsafe-inline` を許可しています。外部オリジンのスクリプトや通信を許可する設定ではありませんが、nonce/hash方式の完全な厳格CSPではありません。
- 画像の寸法検査は `createImageBitmap` 対応ブラウザーで20MP上限を確認します。非対応ブラウザーではファイル容量と形式の検査にフォールバックします。
- SVGの直接読込はセキュリティ上の理由で制限しました。画像をPNG/WebP等へ変換して取り込んでください。
- ブラウザー保存データの暗号化や、端末全体のマルウェア対策を提供するものではありません。

## 4. 未実施・保証しない項目

- 実機iPhone/Android、ペン筆圧、長時間連続描画、低メモリ端末での負荷、実際のPSD互換性は本環境では未検証です。
- 600案すべての完了を意味しません。v55では既存APIと競合しにくい機能を追加した段階です。高度なマスク、非破壊調整レイヤー、完全なベクター編集、フレーム補間、GIF/動画の追加機能などは、各機能専用のデータモデル・回帰テストを作って段階実装する必要があります。
- Chromiumの全画面実動作・全タブでのマウス/タッチ操作試験は完了していません。構文検査・参照検査とコード上の整合性確認を中心とした結果です。
