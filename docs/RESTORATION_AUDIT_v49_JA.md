## どの旧機能が残っているか

### 実装・画面

- 旧版のファイルパスは削除されていません。
- 旧版HTML IDは現行HTMLにすべて残っています。
- `app.js`の名前付き関数宣言はすべて残っています。
- 旧版にあったPSD互換、ホーム、ツール、モード切替、モーション／描画エンジン、モード別ワークスペース、UI整理、モバイル機能のスクリプトは現行の読込対象に残っています。

### ウィンドウ管理

v44の`js/window-manager-v44.js`はZIP内に残っていますが、現行アプリでは同時に読み込まず、拡張版`js/window-manager-v45.js`を読み込みます。v45側はv44の共通クローズ機能に加え、汎用ダイアログ検出、z-indexとDOM順によるレイヤー選択、最前面レイヤー照会、追加復旧処理を含みます。v44とv45を同時ロードするとイベント・MutationObserverが重複するため、v44を実行対象に戻すことは意図的に行っていません。

## 実際に省かれていた内容

コードの機能よりも、`docs/README_JA.md`の説明が大きく短縮されていました。旧READMEにはあった次の説明が現行READMEから欠落していました。

- v36 STUDIO+ 20カテゴリ追加ツールと画材設定・虹色・指先混色
- v41 UI整理（ホーム／エディター、PC／スマホ、8モード別プロファイル、直接整理、プリセット、個別復元）
- v43 コンパクトワークベンチ、横スクロール、モード別折りたたみ
- v44 共通ウィンドウ管理、Esc、背景タップ、戻る、フォーカス、VisualViewport

これらの説明をv49 READMEへ統合しました。現行のv47／v48項目も残しています。

## バージョン不整合

v48配布物は画面・manifest・Service Workerがv48でしたが、`js/app.js`の`PF_APP_RELEASE`だけ`47.0.0`のままでした。v49では49.0.0へ更新しました。これは保存メタデータのアプリ版表示であり、データ形式やDB schemaの変更ではありません。

## 保全方針

- 旧版の実行コードを無差別に上書き・再ロードしない。
- 現行の修正を優先し、旧版との差分で欠落が確認できた説明のみ復元する。
- `.pforge` format version 5とIndexedDB schema version 3を維持する。
- バックアップなしで旧データを移行・削除しない。

## 検査範囲と限界

これはZIP展開、相対パス、HTML ID、関数宣言、HTML script一覧、ソース差分による監査です。すべてのボタン操作・PSDファイル・大容量作品・iPhone／Android実機での動作を網羅したE2Eテストではありません。構造上保持されていることと、実環境で完全動作することは区別してください。
