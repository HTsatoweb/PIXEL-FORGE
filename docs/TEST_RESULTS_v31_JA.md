- `homeButton` のクリックは既存の `goHome` 関数へ接続。
- `goHome` は即時画面遷移後に保存を行い、IndexedDB失敗時は `.pforge` バックアップへフォールバック。両方失敗した場合は編集画面へ戻す。
- `saveProject` の多重実行ガード、保存中ボタン状態、進捗更新（3% / 82% / 92% / 100%）を保持。
- 保存オーバーレイの `busyProgress` / `busyPercent` / `busyBytes` がHTMLに存在。
- `rainbow` プリセットが選択肢・滑らかなストローク描画・幅／不透明度ルールに存在。
- UIカスタマイズの開始・リセット・状態表示IDがHTMLに存在。
- UI配置は `pf-ui-layout-v31-mobile` / `pf-ui-layout-v31-desktop` の専用キーに保存。
- Cache Storage専用削除とオフラインキャッシュ無効化はv30のコードを保持。作品IndexedDBとは分離。
