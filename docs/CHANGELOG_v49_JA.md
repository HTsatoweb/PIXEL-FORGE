# v49.0 変更履歴

## 目的

v44.0を旧版ソース、v48.0を現行ソースとして比較し、現行機能を削除せずに旧版由来の機能・文書・導入説明の保持状態を明確にしました。

## 復元・保全

- v44.0の114ファイルがv48.0にもすべて存在することを確認。旧版パスの削除はありません。
- `index.html`の旧版ID 566件すべて、`help.html`の旧版ID 30件すべてを維持。
- `app.js`の旧版の名前付き関数宣言312件すべてを維持。現行側では追加関数を含め320件。
- v44の機能を含むウィンドウ管理は、二重起動を防ぐため拡張版`window-manager-v45.js`のみを有効化。v44ファイルそのものは削除せず保持。
- v44 READMEから省かれていたSTUDIO+20カテゴリ、v41 UI整理、v43省スペースUI、v44共通ウィンドウ管理の説明を現行READMEへ統合。

## 追加の整合性修正

- アプリ内部の`PF_APP_RELEASE`を、v48.0で残っていた`47.0.0`から`49.0.0`へ更新。
- PWA manifest、ホーム表示、ヘルプ表示、README、起動ガイドをv49.0に統一。
- Service Workerキャッシュ名を`pixel-forge-v49`へ更新し、同梱文書の重複キャッシュ登録を整理。
- `.pforge` format version 5、IndexedDB `PixelForgeDB` schema version 3は変更していません。

## 変更しなかったもの

- 描画エンジン・ブラシ計算・レイヤー構造・アニメーション編集・PSD連携のコードを置き換えていません。
- v48.0の350項目強化センターは維持しています。
- 旧版由来のファイルを削除していません。
