# v53.0 UI再整理・実装範囲

## スマホ

- 片手で押せるメインタブ、ツール、ブラシ、カラー、レイヤー、操作メニューを維持。
- 上部のボタンをよく使う操作に絞り、その他機能を操作グリッドへ移動。
- 設定ドロワーの開閉状態、背景スクリーン、フォーカス／操作可能状態を同期。
- 重複した閉じる行、不要なPC用ボタン、モバイルで高さを取りすぎるガイド表示を整理。
- ノッチ・セーフエリア、仮想キーボード、画面高の小さい端末を考慮。
- 選択メニューは画面内へ収め、開閉中の画面サイズ変化に合わせて位置を更新。

## 小画面PC

- 画面幅に応じてパネル幅と余白を圧縮。
- 画面高が低い場合はヘッダー、コンテキストバー、下部バーを省スペース化。
- ツール・設定パネルの子要素が幅を押し広げないようにし、必要な場所は内部スクロールを使用。
- PCの主要な上部ボタンを隠さず、スマホ用の簡略メニューへ誤って切り替えないことを確認。

## 描画・応答性

- ライブプレビューは画材粒子と虹色分割を抑え、確定時の描画は高品質設定を使います。
- 画材の紙目、粒子、筋、かすれ、毛束、顔料、水分などの差を描画プロファイルへ反映。
- 長いストロークで毎回最大密度の処理をしないようにし、プレビュー負荷を抑えます。

## 既存機能の扱い

画材や編集機能を削除せず、操作入口の位置変更と表示密度の整理を行っています。スマホで上部から移動した機能は「操作」グリッドへ配置し、PCでは既存の上部ボタンを維持します。旧版Markdown資料は保管したままです。
