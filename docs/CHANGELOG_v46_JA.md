# PIXEL FORGE STUDIO v46.0 更新内容

## 監査レポートに基づく修正

- **スマホ設定パネルの重なり順**：`#rightbar` を共通ウィンドウのレイヤー一覧へ登録し、設定パネル・ダイアログ・メニュー・カスタム選択メニューを、表示中の計算済みz-indexとDOM順で並べて閉じるようにしました。
- **追加のCSS競合修正**：既存の `style.css` に `.workspace.panel-open .rightbar { z-index:80!important }` が残っており、設定パネルが背面へ隠れる可能性がありました。v46の最終ウィンドウCSSでこの旧ルールを明示的に上書きし、設定パネルを12020、背景スクリーンを12010に固定しました。
- **画面サイズ追従**：VisualViewportの幅・高さ・オフセット変数を使う `css/window-manager-v44.css` をHTMLから読み込み、Service Workerの必須キャッシュにも追加しました。
- **作品の安全な読み込み**：作品全体の形式・キャンバス寸法・レイヤー／フレーム数・ID重複・画像ソース・端末別データ量・Canvasメモリ見積りを反映前に検証します。現在の表示フレームと参照画像は一時キャンバスへ復元し、さらに非表示の全アニメーションフレーム画像も一意の画像ソース単位で事前デコード検証してから現在の作品へ切り替えます。将来フレームの破損画像も切替前に検出し、途中失敗時は従来の作品を保持します。空フレームも空白セルとして切り替えられるようにしました。
- **大きな作品の入力保護**：ファイルサイズとJSON文字数の上限を設け、過大なファイルは読み込み前に拒否します。
- **必須スクリプト失敗時の復旧**：`app.js` を必須モジュールとして識別し、ロードエラー時に即座に起動エラーと再読み込み操作を表示します。20秒以内にロードされない場合もタイムアウト表示にします。
- **保存後の不要な再読込を削減**：IndexedDBのread-writeトランザクション完了を保存コミットとして扱い、保存直後に巨大なラスター作品レコード全体を再取得する処理を削除しました。
- **画像エンコード時の負荷軽減**：`toBlob()`を優先し、同期`toDataURL()`へのフォールバックは小さいCanvasに限定しました。アニメーションの現在フレームは同じ非同期エンコード結果を再利用します。保存容量の見積りには、現在以外の全アニメーションフレームと参照画像も含め、読み込み時と同じ端末別容量目安を適用します。
- **ウィンドウ監査API**：現在のレイヤー順と最前面レイヤーを診断から参照できるようにしました。PC・スマホのランタイム試験では、それぞれ56項目の構造・CSS・ARIA監査が全項目OKでした。監査の存在確認・ARIA・CSSレイヤー順と、実際のEsc／戻るによる開閉テストは区別して記録します。診断APIはDOMやAPIの存在確認を主目的とし、動作試験の代用とはしません。

## データ互換性と既存機能

- `.pforge`の`PIXEL_FORGE_PROJECT` version 5、IndexedDBの`PixelForgeDB` schema version 3を維持しています。
- PSD互換モジュール、ブラシ・描画エンジン、全制作モード、レイヤー編集、アニメーション、UI整理、端末設定など既存のアプリファイルは削除していません。
- 画像やメモリの安全上限を超えるファイルは、現在の作品を置き換える前に拒否します。これは作品を消す処理ではありません。
- 旧版のコード・文書・マニフェストも履歴確認用に残しています。役割は `LEGACY_FILE_GUIDE_v46_JA.md` を参照してください。

## 検証範囲

Chromiumの隔離ハーネスで、デスクトップ幅1365×900とスマホ幅390×844を使い、起動・Escによる重なったウィンドウの順次クローズ・スマホ戻る操作・スマホ設定パネルの実表示ヒットテスト・正常な小型作品の読込・現行レイヤーおよび将来フレームの破損画像を含む作品の拒否と元作品保持・空アニメーションフレームの保持・フレーム保存シリアライズ・必須app.jsロード失敗時のエラー表示を確認しました。

この隔離ハーネスはHTML／CSS／JavaScriptをインライン化したもので、通常オリジンではありません。そのためIndexedDBへの実保存・再読込は未確認です。iOS／Android実機、全PSD派生形式、大容量作品の性能ベンチマークも未確認です。詳しくは `TEST_RESULTS_v46_JA.md` を参照してください。
