# PIXEL FORGE STUDIO v53.0 変更履歴

## 今回の方針

v52.0をベースに、スマホの設定ドロワー、UIの重なり、選択メニュー、キーボードショートカット、画材描画の負荷と筆跡差を中心に修正しました。既存の描画機能・編集機能・作品形式・保存データを削除する変更は行っていません。UIの配色・暗い作業背景も維持しています。

## スマホUI・パネル操作

- `body.mobile-panel-open` をモバイル設定ドロワーの開閉状態の基準に統一。ドロワーの `collapsed`、ARIA属性、`inert`、背景スクリーンを同じ状態から更新します。
- 閉じるボタン、背景スクリーン、旧IDの閉じる操作を共通のクローズ処理へ集約し、連続クリックで複数の開閉処理が競合しないようにしました。
- モバイル用ドロワーは `transform` で出し入れし、閉じた後は `visibility:hidden` と `pointer-events:none`、`inert` を設定。閉じているパネルがタッチやキーボード操作を奪う状態を避けます。
- ドロワー内の閉じるボタンを1つに統一し、ツールバー内の重複した閉じる行を隠します。検索／一括操作、カテゴリー、ツール一覧、その他操作の順序も整理しました。
- スマホ上部には頻繁に使う操作を残し、STUDIO+、ヘルプ、UI密度、集中表示、強化設定などは「操作」タブにまとめました。機能自体は削除していません。
- タッチ操作中のブラウザー上部・下部UIや仮想キーボードの表示変化で、意図せずドロワーを閉じないようにしています。

## PC・小画面レイアウト

- 小さなPC画面では各コンテナの `min-width` とパネル幅を見直し、右パネル、ツール列、選択メニューが画面外へ押し出されにくいよう調整。
- 低い画面高ではツールバーやヘッダーの高さ・余白を圧縮し、キャンバスの作業領域を優先します。
- スマホではヘッダーの重複項目をまとめ、横幅のはみ出しを抑えました。背景・基本カラーパレットは変更していません。

## 画材の筆跡と描画エンジン

- クレヨン、ワックスクレヨン、チョーク、チョーク粉末、パステル、色鉛筆、木炭、コンテ、オイルパステルについて、粒子の密度・筋・輪郭の崩れ・顔料の乗り方などの違いが出る既存パラメータを描画へ反映。濃さだけを変える筆跡にならないようにしました。
- 紙目、顔料の粒状感、縁の欠け、筆毛の広がり・重なり、水分・乾燥など、各画材の既存設定を維持しつつ、画材別の筆跡が区別されるように改善。
- ライブプレビューは最終描画より軽い密度・分割数で処理し、ストローク確定時には高品質の描画を行うように分離。線を引いている間の重さを抑えながら、完成した線の画材表現を維持します。
- 虹色ブラシのプレビュー分割数は最大180、本描画は最大1200。プレビュー時の下地色サンプリングや粒子・筋の密度も軽量化しています。
- 既存の虹色方向、位相、逆方向、下地色拾い、指先混色の機能は維持しています。

## 選択UI・ショートカット

- カスタム選択メニューを開いている最中に候補の追加・削除・更新が発生した場合、候補一覧を再描画して位置を更新します。元の `<select>` は値・イベントの正本として維持。
- IME変換中、文字入力欄、contenteditable、テキストボックス、キーリピート中はアプリのショートカットを横取りしないようにガードを強化。
- Ctrl/⌘+K は編集欄外の正しいキー操作だけでコマンドパレットを切り替えます。入力中の文字やIME変換との競合を抑制します。

## バージョン・キャッシュ

- アプリ表示・Web App Manifest・Service Workerキャッシュをv53.0へ更新。起動時のモジュール数表示を実際の24モジュールに合わせました。
- 新しいCSS・JavaScriptをService Workerのコアキャッシュへ追加。旧版のMarkdown資料は削除していません。

## 維持したもの

- ホーム、キャンバス、ブラシ80種類、レイヤー、選択・変形、描画・消しゴム・混色、紙質、水彩、虹色、書き出し、作品保存・読込、ショートカット、STUDIO+、UI整理などの既存機能。
- 作品データ形式 `PIXEL_FORGE_PROJECT` version 5、既存IndexedDB `PixelForgeDB` schema version 3。
- 背景の色調・既存の暗色UIの雰囲気。

> 画材の表現はCanvas上の粒子・筆跡・顔料表現を組み合わせた描画モデルです。実際の紙や顔料を完全再現する物理シミュレーションや、全端末のGPUで同じ速度を保証するものではありません。
