# PIXEL FORGE STUDIO v42.0 変更履歴

## モードUIの整理
- 上級者モードの共通ヘッダーを専用表示に分離。上級者は説明・READY・ホーム誘導を持たない小型コマンドレールに変更。
- その他のモードは名称と小さな「＋ 展開」だけを初期表示し、説明文は必要なときだけ開けるよう変更。
- モード選択の適用時にワークベンチエンジンへ明示的に同期し、ホームカード・PC・スマホの切替間で表示がずれる可能性を低減。
- 上級者のクイック操作に基本ツール、元に戻す／やり直し、レイヤー、診断、UI整理などを追加。

## UI整理の強化・不具合修正
- UI整理画面の詳細設定を初期折りたたみにして一覧を見やすく整理。
- カテゴリ単位の一括表示／一括非表示を追加。
- 非表示項目のみを絞り込む切替を追加。検索との併用に対応。
- レイアウト初期化時に保存済みのCSS並び順も再適用し、並び替えが残る不具合を修正。
- 既存の個別表示、直接整理、プリセット、PC／スマホ別・8モード別の設定保存は維持。

## 保護範囲
- 描画処理、ブラシ、作品データ、レイヤー、履歴、PSD処理、IndexedDBのデータ構造は変更していません。
- Service Workerキャッシュをv42へ更新。
