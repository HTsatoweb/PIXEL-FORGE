# PIXEL FORGE STUDIO v39.0 変更履歴

## 主な変更

### スマホ編集画面の再構成
- 旧来の横長コンテキストバー・左ツールバー・旧モバイルドックをスマホ表示で整理し、上部クイック設定、制作画面、下部5タブの構成に変更。
- 右パネルに「ツール／色／ブラシ／レイヤー／その他」のタブを追加。
- モード設定に応じてモバイルツール一覧を絞り込み。
- 44px以上を目安としたタッチ操作面、セーフエリア、狭幅・横向き表示に対応。
- サイズ・不透明度を上部から直接変更できるようにした。

### ピクセルアートの開始経路修正
- モード切替時に選択中ツールが塗りつぶし／移動等のまま残らないよう、ピクセルモードでは実ブラシツールを明示選択。
- 新規ドキュメント作成・プロジェクト読み込み完了イベントを追加し、ピクセルモード時にズームとグリッドを再適用。
- 初期キャンバスを64×64px、透明背景に変更。16／32／64／128／256／512等のサイズ設定は新規作成ダイアログで手動変更可能。
- ピクセル表示は拡大率5×から1ピクセル単位のグリッドを表示する。スマホでは拡大・2本指パンで作業領域を移動。
- ピクセル書き出しは既存の補間無効化処理を維持。

### 互換性
- 既存の作品データ形式、IndexedDB名・バージョン、描画履歴・レイヤー形式を変更しない。
- v38の既存ファイルを保持し、新規JS/CSSとドキュメントのみ追加。

## 制限
- ブラシは実物の毛束・流体・顔料そのものを完全再現する物理シミュレーションではなく、既存2D描画エンジンの特性パラメーターによる近似。
- 今回はモバイル画面構成を大規模改修したが、iOS Safari／Android実機／各種ペンタブレットでの実機確認は未実施。
- 400個以上の独立した新機能を一括実装したという意味ではない。今回はピクセル描画の入口修正とモバイルUIの基盤・操作系の改善が中心。
