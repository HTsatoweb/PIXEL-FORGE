# v28.0 修正・強化点

## 変更の方針

既存の描画エンジンと編集機能を置き換えず、スマホ向けCSS／JSと保存処理の内部を追加・改善しました。追加のモバイル修正は `mobile-experience-v28.css` と `mobile-experience-v28.js` に隔離し、PCレイアウトへの副作用を抑えています。

## 重要な修正

1. **スマホのホーム操作**：編集画面のクイックドックから直接 `goHome()` を呼ぶボタンを追加。
2. **スマホの保存操作**：クイックドックから `saveProject()` を呼ぶ専用ボタンを追加。
3. **保存の応答性**：レイヤー画像を非同期でBlob化し、各レイヤーの前後で描画フレームへ制御を返す方式へ変更。
4. **保存の見える化**：進捗％、レイヤー番号、概算／実容量を表示し、進捗バーをアクセシブルに変更。
5. **ホーム移動中の保存**：作品が未保存の場合に、ホームへ遷移した後も進捗を表示。
6. **サムネイル負荷**：小さなサムネイル用キャンバスへ直接描画し、フルサイズの一時合成キャンバスを避ける。
7. **表示領域**：VisualViewportに合わせて高さ・幅・オフセットを更新。
8. **タッチ操作**：小型画面のドックを横スクロール化し、44px以上の操作対象を基本とする。
9. **設定パネル**：右側の設定ドロワー、背景スクラブ、ダイアログをスマホ向けに再配置。
10. **動き**：押下、画面遷移、設定パネル、進捗カードに軽量モーションを追加。

## 残る確認事項

ブラウザ制約によりiOS Safari／Android Chromeの実機で描画ペン・ファイル保存・IndexedDBの長時間処理を実行確認できていません。コード構造の点検と静的検査は実行しましたが、端末固有の動作は利用者端末での診断が必要です。大切な作品はライブラリ保存に加えて `.pforge` ファイルも別途バックアップしてください。
