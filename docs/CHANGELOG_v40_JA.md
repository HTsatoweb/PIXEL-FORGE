# PIXEL FORGE STUDIO v40.0 変更履歴

## 個別UIの表示カスタマイズ
- モード別ワークベンチの各まとまりに「×」ボタンを追加。
- 非表示にしたまとまりは「非表示」トレイに残り、ワンタップで再表示可能。
- 表示・非表示の設定はモードごとにブラウザー内へ保存。
- ワークベンチ全体を「まとめる／展開」で折りたたみ可能。
- 初心者向け「まずはブラシで描いてみましょう」ガイドにも個別の閉じるボタンを追加。
- 閉じた初心者ガイドはワークベンチ上部の「ガイドを表示」で再表示可能。
- デスクトップとスマートフォンでタップしやすい操作寸法に調整。

## 互換性
- 描画キャンバス、レイヤー、プロジェクト保存形式、IndexedDB schemaは変更していない。
- 非表示設定はUI設定専用のlocalStorageキーに保存。
- Service Workerキャッシュをv40に更新し、新規CSS/JSをコアキャッシュへ追加。

## モバイル表示
- v39のモバイルCSSで常時非表示だった初心者ガイドを、v40ではユーザーが隠していない場合に表示するよう上書き。
- 閉じるボタンはスマートフォンでもタップしやすいサイズを確保。
