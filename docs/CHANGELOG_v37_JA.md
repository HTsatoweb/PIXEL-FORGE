# PIXEL FORGE STUDIO v37.0 — 制作モードとホーム再設計

## ホーム
- ホームに8種類の制作モード選択カードを追加。
- 「はじめて」「イラスト」「アナログ画材」「写真加工」「デザイン」「ピクセルアート」「アニメーション」「上級者」を用意。
- 選択中モードの説明・推奨キャンバス・開始ボタンを追加。
- 選択モードはこのブラウザーのローカル設定に保存。作品ファイル形式には追加しない。
- 既存作品ライブラリ、検索、並べ替え、バックアップ、復元機能は維持。

## モードに応じたエディター構成
- エディターのコンテキストバーからモードを変更可能。
- モードごとに右側の設定パネルと左側のツールを整理。
- 上級者モードでは全パネル・全ツールを表示。
- はじめてモードでは基本ツールに絞り、4ステップの簡易ガイドを表示。
- 新規キャンバス作成時にモード別の初期寸法・DPI・背景・ブラシを設定。
- 既存キャンバスのモード切替では作品画素やレイヤーを変更しない。

## 互換性・保護
- PIXEL_FORGE_PROJECTの保存形式、IndexedDBのDB構造、作品ライブラリのIDを変更しない。
- 元の描画エンジンと既存ブラシロジックを置き換えない。
- Service Workerキャッシュ名をv37.0へ更新。
- v36.0までのファイル・ドキュメントを残し、新規CSS/JSを追加。

## 制限
- モードは既存機能の表示整理と新規作成時のプリセットであり、未実装の写真AI補正・完全なピクセルスナップ・高度な動画編集機能を新設したものではない。
- 画面幅ごとの自動レイアウトはCSSとブラウザーのレスポンシブ機能を使用。実機での全OS・全ペンタブレット検証は別途必要。
