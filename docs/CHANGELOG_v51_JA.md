# PIXEL FORGE STUDIO v51.0 — 修正内容

## スマホの設定パネル
- エディタとウィンドウ管理で異なっていたスマホ判定を共通化。タッチ対応PC・タブレット・回転時の状態不一致を抑制。
- パネルを display 切替で出し入れせず、単一の transform 状態で開閉するよう最終CSSを整理。開閉アニメーションの競合を無効化。
- 閉じたパネルを inert にし、フォーカスやタップが背面へ抜けないように改善。
- ソフトキーボードやブラウザバーによる visualViewport の変化を、パネルを閉じるイベントとして扱わない。

## オリジナル選択UI
- ポップアップをスクリーン幕・設定パネル・メニューより前面に表示するレイヤー計算を追加。
- visualViewport のサイズ・オフセットを使い、画面端／拡大表示／ソフトキーボード表示中の配置を補正。
- visualViewport の resize / scroll でも選択メニューを再配置。元の select 要素・イベント・保存値は維持。
- ホームの制作モードカードに矢印キー・Home / End の移動操作を追加。

## 画材表現
- クレヨンを欠けた顔料粒と紙目の抜け、ワックスクレヨンを平たいワックス片、オイルパステルを幅広い重なりと丸い顔料層で描き分け。
- チョークを角のある粒・短い擦過痕、チョークダストを拡散した粉雲、木炭を濃い擦れ、コンテを硬い顔料片として描き分け。
- パステルのベルベット状の重なりを強化。色鉛筆に交差する短いハッチを追加し、単なる不透明度差にならないよう形状を変更。
- 既存の滑らかなストローク骨格とクリップ範囲は維持。テクスチャ生成は決定論的な乱数と既存の低メモリ上限を使用。

## PC・スマホのレイアウト
- 小型ノートPCでツール列・コンテキストバーを横スクロール可能にし、右パネルと作業領域の重なりを抑制。
- 低い画面高ではヘッダー・パネル・フッターの密度を調整。
- 460px以下のスマホでトップバー、下部ツール、設定タブの幅を再調整。
- アプリ背景・キャンバス背景の配色は変更していません。

## 互換性・維持
- v50までのHTML、描画エンジン、PSD互換、保存形式、レイヤー、アニメーション、既存モジュールを削除していません。
- Service Worker のキャッシュキーを v51 に更新し、旧キャッシュとの混在を避ける。
