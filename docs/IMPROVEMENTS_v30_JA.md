# v30.0 UI・操作改善

1. スマホヘッダーのflex余白を修正し、ホーム等の操作が右端に追いやられないようにしました。
2. 320〜360px向けにロゴと操作ボタンを段階的に圧縮しました。
3. 下部クイックドックはLTR・左詰めの順序を固定しました。
4. ヘッダー・ツール・ホーム操作に短いネオン系の押下／浮上フィードバックを追加しました。
5. 選択中ツールの発光輪郭と保存パネルの走査光を追加しました。
6. アニメーション低減設定を尊重します。
7. 設定画面にCache Storageのサイズ・ファイル数表示を追加しました。
8. Cache Storage削除・Service Worker解除によりキャッシュ0を実現します。
9. 専用フラグでオフラインキャッシュの自動再作成を抑止します。
10. オフラインキャッシュを再び有効化できます。

既存の描画・レイヤー・水彩・PSD・フレーム・保存形式は置き換えていません。
