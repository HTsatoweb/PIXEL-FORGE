# PIXEL FORGE STUDIO v35.0 変更履歴

## UI・アニメーション

- すべての通常ボタンに押下・クリック・キーボード操作の触覚的な視覚フィードバックを追加。既存のクリック処理や操作タイミングは変更しない。
- 設定モーダル、通常ダイアログ、コマンド画面、パネル展開に個別の登場アニメーションを追加。
- ウィンドウ、サイドパネル、ヘッダー、ドック、UI配置編集対象の位置変化を検出し、加算型FLIPアニメーションで自然に移動。既存のtranslate / transformをできるだけ保持する。
- ドラッグ中・キャンバス・レイヤー一覧の高頻度更新は移動監視から除外し、描画入力やレイヤー描画を妨げない。
- OSの「視差効果を減らす」とアプリ内の「アニメーションを減らす」を尊重。

## 350個の微調整コントロール

- 35種類の既存筆・水彩・紙質パラメーターに、それぞれ10個、合計350個の追加微調整スライダーを実装。
- 50を中立値として、各スライダーの小さな補正を合算し、実際の既存設定欄へ反映。元の描画エンジンや設定欄を置き換えず、補正は各パラメーターの最小・最大値内に制限。
- 7カテゴリに分け、検索、全展開、全折りたたみ、全微調整の中立化を追加。パネル展開時に初めてコントロールを生成する遅延構築で初期負荷を抑制。
- 微調整値は独立したバージョン付きLocalStorageキーに保存し、専用ファイルで書き出し・読み込み可能。既存の .pforge / .pfarchive / IndexedDB作品データには触れない。

## 互換性

- 作品DB `PixelForgeDB` と既存スキーマ、作品ストア、書き出し形式は変更しない。
- Service Workerのキャッシュ名をv35.0へ更新し、新規CSS/JSを必須キャッシュへ追加。
- アプリ版表示を35.0.0へ更新。
