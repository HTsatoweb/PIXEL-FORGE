# PIXEL FORGE STUDIO v50.0 — 強化カバレッジ一覧

## 数え方と注意

本資料の「100／100／300」は、独立した新規ツールを500個作ったという意味ではありません。既存機能を削除せず、画面幅・操作・画材・描画品質・保存・診断を細かく改善／維持確認するための**改善ポイント数**です。v50.0で実際にコード変更した主な項目は、設定ドロワーの単一開閉制御、モバイルスタッキング／ヒットテスト修正、明示的なpanel(open) API、PC密度・集中モード、自然画材9種類の質感分化、低メモリ時の粒子上限、粒子位置サンプリングの弧長テーブル化です。その他は既存機能の維持・品質確認対象として整理しています。

## v50.0で実際に変更したコード上の改善

- `PF_EDITOR_ACTIONS.panel(open)` は `open=true/false` を明示でき、引数なしでは従来のトグルとして動作します。
- モバイル設定パネルは既存 `#mobilePanelScrim` を再利用し、別スクリーンを重ねて生成しません。
- 設定パネルを開いたときだけ `.workspace` の重なり階層を調整し、ヘッダーのボタンがパネルの×を覆わないようにします。
- ×・Esc・ブラウザー戻る・背景タップは一つの状態へ集約し、VisualViewportの高さ変更では勝手に閉じません。
- 小画面PCでは密度切替／キャンバス集中モードを用意し、右パネル幅と上部更新通知の高さを抑えます。
- クレヨン／ワックスクレヨン／オイルパステルはワックス筋と顔料片、チョーク／木炭／コンテは粉粒子と堆積、パステルは柔らかい顔料雲、色鉛筆／黒鉛鉛筆は方向性ハッチを描き分けます。
- 粒子のストローク上の位置決めを全点走査から弧長テーブル＋二分探索へ変更し、長い線の素材描画負荷を軽減します。
- 低メモリ時は画材粒子数をさらに制限します。

## 既存機能の扱い

v49.0までのHTML／JS／CSS、ホーム機能、350項目強化センター、制作モード、描画ツール、レイヤー、アニメーション、PSD関連、保存形式、ヘルプを削除しません。v50のUIと描画処理は既存API・既存描画エンジンに追加接続しています。
