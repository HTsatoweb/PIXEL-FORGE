# PIXEL FORGE STUDIO v30.0 変更履歴

## スマホエディタ上部の配置を修正
- ロゴの `flex: 1` が残り幅を占有して操作ボタンを右端へ押しやる構造を修正。
- スマホではロゴを最大幅固定の可変領域にし、コマンド・ホーム・全体設定・新規・保存をロゴの直後から左詰めで並べる。
- 320px以下ではロゴとアイコンボタンをさらに圧縮し、ヘッダー内の横はみ出しを抑制。
- ボタン名を視覚的に省略しても `title` / `aria-label` を維持。
- 下部クイックツールの並び方向をLTRで固定し、左端から表示する。

## サイトキャッシュを0にする設定
- アプリ全体設定にサイトキャッシュ管理を追加。
- Cache Storage の容量とファイル数を表示。
- 「キャッシュを0にする」でPIXEL FORGEが管理する `pixelforge-web-` キャッシュだけを削除し、Service Worker登録を解除。
- オフラインキャッシュ無効化フラグを保存し、アプリ起動時にService Workerを再登録しない。
- 「オフラインキャッシュを再有効化」で再登録できる。
- IndexedDBの作品、.pforge、ブラシ・画面設定は削除対象にしない。
- ブラウザ内部のHTTPメモリ／ディスクキャッシュはWeb標準APIから消去できない旨を明記。

## 近未来モーションと操作感
- ヘッダーに軽量なネオン走査ラインを追加。
- ツール、ボタン、ホームカード、パネル、保存カードに短い押下・浮上・発光遷移を追加。
- 選択中ツールの輪郭パルス、保存カードの走査光を追加。
- `prefers-reduced-motion` とアプリ内の「アニメーションを減らす」に対応。

## 互換性
- v29の描画エンジン、ブラシ、水彩、消しゴム、PSD、レイヤー、フレーム、作品形式、既存ID・イベント経路を保持。
- Service Workerのキャッシュバージョンを v30.0 に更新。
