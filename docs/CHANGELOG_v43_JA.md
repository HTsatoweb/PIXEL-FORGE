# PIXEL FORGE STUDIO v43.0 変更履歴

## 全モード共通ワークベンチの省スペース化
- 折りたたみ状態をCSSから明示できるようにし、折りたたみ時の高さをPC約24px、スマホ約28pxに固定。操作は小型の「＋」ボタンから再展開できます。
- 展開中は各モードの操作列を横スクロールに統一。ツールを削除せず、折り返しによる高さ増加とボタン同士の重なりを抑制します。
- PCではホイール操作で横スクロールできるように改善。キーボード・タッチでの通常スクロールも維持。
- ピクセルアートのツール／設定／パレット列と、画材調整スライダーもコンパクトに再配置。

## UI重なり防止
- PCの「UI整理」ボタンをエディターのステータスバー内に移し、設定パネルのブラシスライダーを覆わないように変更。
- ホームとスマホでは既存のフローティング入口を維持。スマホで設定パネルを開いたときはフローティング入口を隠し、パネル内容との衝突を回避。
- ステータスバーの高さを縮小し、キャンバスの表示領域を確保。

## 機能・データ保護
- 8つの制作モード、モード専用コマンド、個別のUI表示／非表示、非表示UIの復元、UI整理プリセットは維持。
- 描画エンジン、ブラシ設定、作品データ、レイヤー、Undo履歴、PSD互換処理、IndexedDBスキーマは変更していません。
- Service Workerキャッシュをv43へ更新。
- 初回利用時・折りたたみ設定が未作成の場合は8モードすべてを最小バーで開始。既に保存済みのモード別展開設定は上書きしません。
