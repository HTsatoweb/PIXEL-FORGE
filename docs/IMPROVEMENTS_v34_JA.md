# v34.0 改善内容

## スマホ・PC UI

- 760px以下、タッチ端末、短い横向き画面でエディタ上部を必ず左起点の横並びにする。
- ブランドと操作ボタンの古い横方向移動量をモバイルで0に固定し、前バージョンの位置データがホーム／保存ボタンを右端へ押しやらないようにする。
- ボタン順序のカスタマイズと縦方向の微調整は維持。狭い画面では横スクロールも利用可能。
- UI配置編集ハンドルをホーム操作、ブラシ詳細、虹色設定、タイムライン、各種モーダル、その他の画面内コントロールまで拡張。
- 重なったセレクターに同じ要素が複数回登録されないよう重複を抑止。

## ブラシ詳細・虹色

- 画材ごとの84個のフォームコントロールを個別プロファイルに保存。
- 指先強度0%を有効値として保持。
- 他のブラシへ現在の設定一式をコピー。コピー元のstateは変更しない。
- 虹色の開始色相と方向反転を追加。下色サンプリングも反転方向に追従。
- 虹色位相・逆方向・指先合成参照をプロジェクトメタデータと互換用フィールドの両方へ記録。
- 旧ファイルの読み込み時、ファイルに設定値が含まれている項目は既定値処理で上書きしない。

## データ保護・ファイル整理

- `PixelForgeDB` の名前とバージョン3を維持。
- 作品ストアは削除・初期化しない。
- Service Workerキャッシュは新しいディレクトリ構造へ更新。
- HTMLはルート、JavaScriptは `js/`、CSSは `css/`、画像は `assets/images/`、Markdownは `docs/` に配置。ルートService Worker `sw.js` はスコープ維持のため残す。
