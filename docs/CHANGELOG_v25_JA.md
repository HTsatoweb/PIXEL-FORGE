# PIXEL FORGE STUDIO v25.0 — モーション・操作デバッグ強化

## 主な変更

- ボタンに短い押下フィードバックを追加。クリック処理自体を遅らせず、既存のボタンイベント・ファイル選択・ダイアログ操作は維持。
- PCのホバー時に軽い浮き上がり、タッチ時に控えめな押し込みを追加。
- 設定パネルの展開時に内容を短くフェード／スライド表示。
- モバイル設定ドロワーのスライドイン、設定ダイアログの表示アニメーションを追加。
- レイヤー行に内部IDを持たせ、レイヤーの並べ替え時にFLIP方式で実際の位置差をアニメーション。2枚のレイヤーを実際に上下入れ替えるChromiumテストでDOM順序変更と `Element.animate()` の発火を確認。
- 新しいレイヤーは短いフェードインで表示。
- OSの `prefers-reduced-motion` とアプリ設定の「動きを減らす」のどちらでも装飾モーションを停止。
- 描画キャンバス自体には重いフィルター・常時アニメーションを追加せず、描画処理と独立。
- Service Workerのキャッシュ名をv25へ更新。起動必須ファイルと任意ファイルを整理。
- 未使用の旧Worker `water-worker.js` と配布に不要な古いテスト実行スクリプト・検証用ベースラインを削除。実行に必要な `water-worker-v8.js` は維持。
- v24までの主要ID 260個、消しゴム、設定自動保存、PSD互換、モバイルUI、作品ライブラリ、ヘルプを維持。

## ファイル整理

以下は実行時に読み込まれていないことを確認して配布物から除外しました。

- 旧版Worker `water-worker.js`（実際のWorker生成先は `water-worker-v8.js`）
- v22～v24の開発用スモーク／検証Python・CJSスクリプト
- 検証専用IDベースラインファイル

本体のJavaScript、CSS、HTML、Worker、アイコン、マニフェスト、起動スクリプト、ヘルプ、変更履歴は削除していません。

## 検証範囲

- 既存IDの保持・重複、ローカル参照、Service Workerキャッシュ対象、PWAアイコン、主要UI要素、モーション制御などの静的検査。
- Chromiumでスマホ縦・スマホ横・PCを使用した既存操作54項目の回帰テスト（54/54）。
- ボタン押下、設定ドロワー、ダイアログ、パネル展開、Reduced Motionの操作テスト16項目（16/16）。
- 実際のiPhone Safari／Android実機はこの作業環境から直接操作できないため、実機チェックリストは引き続き必要。

「検証項目数」は検査した条件数であり、同じ数の独立したバグ修正を意味しません。実際に見つかった問題と修正内容を区別して記録しています。
