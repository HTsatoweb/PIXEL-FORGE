# PIXEL FORGE STUDIO v41.0 検証記録

## 静的確認
- 新規UIカスタマイズJSの構文検査。
- index.html のCSS/JS参照先が存在すること。
- Service Worker のコアアセット登録とキャッシュバージョン更新。
- v40からの既存ファイル欠落がないこと。
- ZIP整合性検査。

## UIハーネス結果
- 実際のindex.htmlからスクリプトを除いたDOM構造を使ったChromiumテストで、8種類のホームモードカード、23個の左ツール、22個の右設定パネルを検出。
- PC／スマホ・8モード別の独立した表示設定スロットは、静的DOM構造で1,278と算出。
- ホームのピクセルアートカードおよび実設定パネルの非表示・再表示が成功。
- 320、360、390、430、760、768、900、1024、1365、1920px幅でページ横はみ出しなし。
- UI整理パネルを320×720、360×800、390×844、430×932、760×850、768×850、1365×900で開き、パネルが画面幅内に収まることを確認。
- JavaScript実行時エラーなし（UIハーネス）。

## UIハーネスで確認する項目
- PC・スマホの設定プロファイルが独立していること。
- 8モードのエディター設定が独立していること。
- ホームのモードカード・ライブラリ部品の個別非表示／復元。
- エディターの上部操作・左ツール・右パネルの個別非表示／復元。
- 直接整理モードの×オーバーレイとクリック抑止。
- UI検索、すっきり／集中／標準プリセット。
- 表示密度、サイズ、幅、配置などの設定保存と適用。
- 表示状態を切り替えても作品データ／キャンバスDOMを変更しないこと。
- 320〜1440px幅でドキュメント横はみ出しがないこと。

## 限界・未検証
- 独立設定スロットはUIパーツの表示・配置の組み合わせであり、同数の新規描画機能を意味しない。
- iOS Safari、Android実機、各種ペンタブレットは別途実機確認が必要。
- ブラウザー環境によってlocalStorageが利用不可の場合、設定は保存されない可能性がある。
