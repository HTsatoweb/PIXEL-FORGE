# PIXEL FORGE STUDIO v47.0 はじめに

## 起動

1. ZIPを新しいフォルダーへ展開します。
2. Windowsは `run_local_server.bat`、macOS/Linuxは `run_local_server.sh` を実行します。
3. 表示されたローカルURLをPCで開きます。スマホは同じWi-Fi上でPCのLAN IPと同じポートを開きます。
4. IndexedDB、Service Worker、ファイル読込・保存を安定して使うため、`file://`直開きではなくローカルサーバー経由で起動してください。

## v47.0で直した設定パネル

- PCでは設定パネルを閉じた後にキャンバスがリサイズされても、設定パネルを勝手に再表示しません。
- スマホでは上部の×、検索バー下の「閉じる ×」、Esc、ブラウザー戻る操作で設定パネルを閉じられます。
- モバイル設定パネルの検索バー、一括操作ボタン、カテゴリータブが同じ場所に重ならないように並び順と固定位置を修正しました。
- 閉じる処理は合成クリックではなく、同じ状態更新関数を直接呼び出します。
- 検索欄右の×は検索文字だけを消去します。設定パネルを閉じる操作は「閉じる ×」です。

## 既存作品の引き継ぎ

同じブラウザー・同じオリジン・同じポートで開けば、従来のIndexedDB作品を引き継げます。フォルダーやURL／ポートを変える場合、元の環境でホーム画面のバックアップ機能を使って`.pfarchive`または`.pforge`を書き出してから、新環境で復元してください。

## データ形式

`.pforge`の`PIXEL_FORGE_PROJECT` version 5、`PixelForgeDB` schema version 3を維持しています。
