# PIXEL FORGE STUDIO v49.0 はじめに

## 起動

1. ZIPを新しいフォルダーへ展開します。
2. Windowsは `run_local_server.bat`、macOS/Linuxは `run_local_server.sh` を実行します。
3. PCでは表示されたlocalhost URLを開きます。スマホは同じWi-Fi上でPCのLAN IPと同じポートを開きます。
4. IndexedDB、Service Worker、ファイル入出力を安定して使うため、`file://`直開きではなくローカルサーバー経由で起動してください。

## 既存作品の引き継ぎ

- 同じブラウザー・同じオリジン・同じポートで開けば、従来のIndexedDB作品を引き継げます。
- フォルダーやURL／ポート、ブラウザーを変える場合は、元環境のホームから `.pfarchive` または `.pforge` を別の場所へバックアップし、新環境で復元してください。
- IndexedDBは `PixelForgeDB` / schema version 3、`.pforge`の`PIXEL_FORGE_PROJECT` version 5を維持しています。
- 大切な作品は、更新前に `.pforge` と `.pfarchive` の両方でバックアップしてください。

## 旧版から引き継いだ機能

- STUDIO+の20カテゴリ追加ツール、各ブラシ・画材設定、虹色描画、指先混色。
- v41 UI整理のホーム／エディター、PC／スマホ、8モード別プロファイル、表示復元、UI密度・パネル幅などの設定。
- v43ワークベンチのコンパクト表示、横スクロール、モード別の折りたたみ設定。
- v44由来のウィンドウ共通管理、Esc、背景タップ、スマホ戻る、最前面判定、フォーカス復帰。
- v47の設定パネル閉じる処理修正。
- v48のホーム100・エディター200・連携UI50の強化センター。

UI整理の「非表示」は削除ではありません。作品データ、レイヤー、描画履歴、ブラシ、保存形式には触れず、表示設定だけを切り替えます。ウィンドウ管理の実行モジュールはv45版であり、v44版スクリプトは二重イベント登録を避けるため実行対象にしていません。
