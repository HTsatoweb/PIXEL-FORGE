# PIXEL FORGE STUDIO v45.0 変更履歴

## 起動高速化・進捗表示
- 19本の既存スクリプトに起動計測モジュール1本を加えた計20本を、元の順序を保った `defer` 読み込みへ統一し、HTML解析と初回描画をスクリプト実行から分離。
- 起動開始直後から進捗バー・処理段階・経過時間を表示。実際のスクリプト読み込み件数とアプリ初期化段階を反映。
- 初期化が7秒を超えた場合、処理が継続中であることを明示。エラー時は再読み込み操作を表示。
- 初回起動時のホーム画面を維持し、進捗表示は画面操作を妨げない。
- `PerformanceObserver` でLong Task・レイアウトシフトを記録し、端末診断へ計測値を追加。

## IndexedDB・作品ライブラリの高速化
- 自動保存復元の通常経路では `autosave` ポインターを先に読み、正常なら全作品 `getAll()` を実行しない。
- IndexedDBから既に取得した自動保存オブジェクトはそのままプロジェクトデコーダーへ渡し、巨大作品の不要なJSON再直列化・再解析を省く。
- 前回作品のレイヤー復元中も進捗バーを更新し、レイヤー単位で描画フレームへ処理を譲る。
- 作品ライブラリは小さなメタデータ一覧を最初に表示し、プロジェクト全データの走査を初期表示から分離。
- ライブラリの整合性修復は `getAllKeys()` でキーだけを比較し、不足している作品のみ個別読込。
- サムネイル再生成は不足分・未生成分だけに限定し、作品単位でアイドル／描画フレームへ処理を譲る。
- 旧形式の大容量autosaveは、作品本体を通常の作品レコードへ保全したうえで軽量ポインターへ移行し、毎回の重複読込・サムネイル再生成を防ぐ。
- `getAllKeys()` 非対応環境向けにIndexedDBカーソルのキー収集フォールバックを追加。
- 旧形式データ・不正な保存ポインターは互換フォールバックを維持。
- 作品データ・IndexedDBスキーマ・PSD形式・保存形式は変更せず、削除・一括変換も行わない。

## ウィンドウ閉鎖・復旧の強化
- ウィンドウ管理をv45へ更新。既知のモーダルに加え、未登録の `data-pf-window-root` / `role=dialog[aria-modal=true]` を自動検出。
- モジュール側の閉じるイベントが欠落しても、表示状態・ARIA・スクロール状態を復旧する強制クローズ経路を追加。
- モバイル／ペン入力で背景部分をタップした場合の閉鎖に対応。
- Studio+ と UI整理の既存クリーンアップを呼び出したあと、残留する `is-open` / body class を強制解除。
- MutationObserverの対象判定を軽量化し、ダイアログ状態と無関係なDOM変更での全走査を抑制。
- 同じbody classを繰り返し変更しないようにし、監視コールバックの再発火を抑制。

## 注意・検証範囲
- この更新は小さな追加UI改善を含みますが、200個の独立した新規描画ツールを追加したと表現していません。作品保全・起動速度・閉じる復旧を優先しています。
- 静的構文・参照・アーカイブの検査と、閉鎖マネージャーの最小DOMフィクスチャでの開閉確認を実施。
- この実行環境ではローカルURL／file URLへのChromiumナビゲーションが管理ポリシーで遮断され、アプリ全体のPC・スマホE2Eを完了できていません。実機での最終確認が必要です。
