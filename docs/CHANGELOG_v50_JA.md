# PIXEL FORGE STUDIO v50.0 — 変更履歴

## モバイル設定パネルのちらつき・閉じられない問題

- 既存 `#mobilePanelScrim` を唯一の背景スクリーンとして再利用し、重複したdrawer-scrimの生成を排除。
- `PF_EDITOR_ACTIONS.panel(open)` に明示的な開閉引数を追加。従来どおり引数なしはトグル。
- スマホの設定カテゴリ切替で `panel(true)` を呼んでも、すでに開いているパネルが閉じないように修正。
- `.workspace` のスタッキング階層をパネル表示中のみ引き上げ、上部ヘッダーのボタンがパネルの×を覆う問題を修正。
- ×・Esc・戻る・背景クリックの閉じる状態を同期。VisualViewportの高さ変化では閉じない。
- 旧drawerアニメーションとの競合を抑止し、`transform` の遷移を一本化。

## PC・小画面対応

- 自動／コンパクト／ゆったり密度切替。
- キャンバス集中モードとショートカット。
- 1280px以下、900px前後、低い画面高向けの上部バー・コンテキストバー・右パネル最適化。
- 小PCの更新通知を低背化し、画面の作業領域を確保。
- 右パネルの幅下限を調整。

## 自然画材エンジン

- クレヨン系：ワックスの方向筋、欠けた顔料片、押し付けムラ。
- チョーク／木炭／コンテ系：粉粒子、粒子塊、柔らかな粉体堆積。
- パステル：ベルベット状の顔料雲と方向性のある面。
- 色鉛筆／黒鉛鉛筆：方向性のあるハッチ、紙目、微細な粒子。
- 低メモリ時の粒子数上限を引き下げ。
- 粒子配置の位置検索を弧長テーブル＋二分探索にして長いストロークの計算量を抑制。
- 9画材のオフスクリーン描画差別化診断を追加。

## 互換性

- v49.0の既存ファイル・UI・制作モード・ツール・保存形式は削除しない。
- `.pforge` version 5、IndexedDB schema version 3を維持。
- 新規CSS／JSはService Workerのキャッシュ対象に追加。

## UI整理ボタンの重なり防止

- PCエディターでは「UI整理」を下部の横幅いっぱいのステータスバーから上部ツールバーへ移動。
- 右パネルのブラシスライダーや画材設定を覆わないよう、アイコンのみのコンパクトボタンに変更。
- スマホでは設定ドロワーを開いている間だけフローティングUI整理ボタンを隠し、閉じた後に復帰。
