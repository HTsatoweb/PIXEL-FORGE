# PIXEL FORGE STUDIO v42.0 検証記録

## 静的・構造検査
- 変更したJavaScriptファイル3本の構文検査。
- 全JavaScriptファイルの構文検査。
- index.htmlのCSS／JavaScript参照先、manifest JSON、Service Workerキャッシュ名と登録アセットを確認。
- 元のindex.html DOMで左ツール19種、右設定パネル22個が維持されていることを確認。

## Chromium DOMハーネス検査
※描画エンジン本体を除いた、実際のindex.html構造＋モード／ワークベンチ／UI整理スクリプトでの検査です。
- 8モードを往復切替し、セレクターとワークベンチのモードIDが一致。JavaScript実行エラーなし。
- 上級者では19ツール・22パネルすべてがモードフィルターで非表示にならないことを確認。
- 上級者ヘッダーにFRAME ANIMATION、READY、ホーム、説明文が出ないことを確認。
- FRAME ANIMATION表記とフレーム追加操作はアニメーションモードだけに出ることを確認。
- ほかのモードの説明は「＋ 展開」で開閉でき、初期状態で閉じていることを確認。
- ワークベンチの折りたたみ／展開、モード別UIのカテゴリ一括表示／非表示、非表示項目フィルターを確認。
- UI整理の詳細設定が初期折りたたみで、カテゴリ一括操作と非表示フィルターの組み合わせが正しいことを確認。
- 320、360、390、430、760、768px幅でUI整理パネルの横はみ出しなし。
- 並び替え後のレイアウト初期化でinline orderが標準順へ戻ることを確認（例：10 → 0）。

## 原因として特定した不具合
- 上級者モードのツール許可リストは `allTools` 配列でしたが、選択中ツール検査で `Set.has()` を呼んでいました。上級者へ切り替えると `permitted.has is not a function` が発生し、モード適用が途中で止まる原因でした。常にSetへ正規化するよう修正しました。
- UI整理の「レイアウト初期化」は保存済みの並び順を消してもDOMのinline orderを再適用していませんでした。初期化時に標準順を適用するよう修正しました。
