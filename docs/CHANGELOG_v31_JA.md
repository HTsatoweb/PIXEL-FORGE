# PIXEL FORGE STUDIO v31.0 — UIカスタマイズ & RAINBOW BRUSH

## v31.0 の変更

### スマホ・エディタ上部の配置修正
- 既存のモバイルCSSに残っていた `.brand { flex: 1 }` と幅指定の競合を、v31専用CSSで上書き。
- ロゴを固定幅にし、コマンド・ホーム・設定・新規・保存をロゴ直後から左詰めに配置。
- 380px以下ではロゴとボタンをさらに圧縮し、横幅が狭い場合は上部バー内でスクロール可能に。
- メニュー・書類名・重複するヘルプ／パネルボタンは小画面で非表示にし、主要操作の幅を優先。
- ホーム画面のモバイルヘッダーも左詰めに統一。

### UI配置カスタマイズ
- アプリ全体設定に「エディタUIの配置カスタマイズ」を追加。
- 編集モードでは上部バー、サイズ・ズームバー、左ツールバー、右設定パネル、下部クイックツールにドラッグハンドルを表示。
- パネルはドラッグして移動可能。少なくとも一部が画面内に残るよう移動範囲を制限。
- 上部ボタンと下部クイックツールはドラッグで順番を入れ替え可能。
- 配置と順序は localStorage の専用キーへ保存し、スマホ／PCで別々に記憶。
- 初期配置へのリセット、編集完了、Escapeキーによる終了を追加。

### 虹色ブラシ
- ブラシ一覧に「🌈 虹色ブラシ」を追加。
- 既存の連続ストローク／リボン描画経路を使い、色の点描ではなく滑らかな色相グラデーションで描画。
- 筆の太さ・不透明度など既存のブラシ設定と組み合わせ可能。
- 既存のブラシ設定保存の仕組みを利用し、選択したプリセットを保持。

### 近未来モーション
- ヘッダーのネオン走査ライン、ボタンの押下・ホバー反応、選択ツールの発光輪郭を追加。
- UIカスタマイズ時にパネルの輪郭と移動ハンドルを強調。
- `prefers-reduced-motion` とアプリ内の「アニメーションを減らす」設定を尊重。

### 既存機能の維持
- v30の保存進捗オーバーレイ、IndexedDBライブラリ保存、`.pforge` 外部バックアップ、ホーム移動時のバックアップ保護を維持。
- v30の専用Cache Storage削除／Service Worker解除／再有効化機能を維持。
- v30までのHTML IDはすべて保持。
- 既存の描画、レイヤー、水彩、PSD互換、タイムライン、画像読み込み、書き出し等の既存ファイルと入口を削除していません。

## 使い方
1. 歯車ボタンから「アプリ全体設定」を開く。
2. 「エディタUIの配置カスタマイズ」→「配置をカスタマイズ」を押す。
3. ⠿ ハンドルをドラッグして各パネルを移動。上部／下部のボタンをドラッグして並び順を変更。
4. 画面上部の「完了」を押す。配置は端末種別ごとに保存されます。
5. 元に戻す場合は設定内の「初期配置に戻す」を使用。

虹色ブラシは、右側のブラシ設定にあるブラシ種類から選択します。
