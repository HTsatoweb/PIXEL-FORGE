# PIXEL FORGE STUDIO v40.0 検証記録

## 静的確認
- 個別UI制御スクリプトのJavaScript構文検査
- HTMLから参照する新規CSS/JSの存在
- Service Workerのコアアセット登録
- v39ファイルの保持
- ZIP整合性

## 実装上の動作
- 各ワークベンチの機能まとまりを個別に非表示化
- 非表示トレイから対象まとまりを再表示
- モード単位の非表示状態保存
- ワークベンチ全体の折りたたみ・展開
- 初心者ガイドの非表示・再表示

## 注意
ブラウザー実機での手動クリック試験、Safari/iOS/Android実機試験は本記録の作成時点で完了していない。JavaScript構文・ファイル整合性の検査通過を実機の完全動作保証とは区別する。

## ワークベンチDOMテスト（Chromium）
- はじめてモードの3つのセクションに閉じるボタンが付くこと
- 閉じた項目が個別の復元トレイに登録され、復帰できること
- 同じモードのDOM再描画後も非表示設定が再適用されること
- 複数の非表示項目を「すべて表示」で復帰できること
- ワークベンチ全体の折りたたみ／展開
- 初心者ガイドの×操作と上部ボタンからの復帰
- ピクセルモードのツール・設定・パレットの個別表示制御
- 320、360、390、430、768、1024、1440pxの各幅でドキュメント横はみ出しなし（UIハーネス）

注：ブラウザーのポリシーでローカルHTTPおよびfile URLによる製品全体の起動は遮断されたため、ワークベンチHTML構造を用いたChromium DOMハーネスで操作ロジックとv40 CSSを検証した。
