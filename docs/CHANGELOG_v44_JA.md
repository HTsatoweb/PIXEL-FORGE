# PIXEL FORGE STUDIO v44.0 変更履歴

## 致命的なウィンドウ閉鎖不具合の対策
- 新しいキャンバスに閉じる×を追加。背景クリック、Esc、キャンセルでも閉じられるように整理。
- ガイド、設定、診断、インストール案内、コマンドパレットを共通の閉じる処理へ接続。
- Studio+ と UI整理の動的ウィンドウも最前面判定・一括復旧の対象に追加。
- PCでは×／背景クリック／Esc、スマホでは×／背景タップ／ブラウザ戻る操作に対応。
- `Alt+Shift+W` で現在の最前面ウィンドウを閉じるショートカットを追加。
- ウィンドウ監視の対象を `class`／`hidden` に限定し、監視対象の `aria-hidden` を監視処理自身が再更新する自己発火ループを防止。
- 監視コールバックを管理対象のウィンドウ・メニュー・設定パネルに限定し、無関係なDOM変更による不要な復旧処理を削減。
- スマホ設定パネルの閉じる処理から合成 `.click()` を排除。閉じるボタン監視の再入・再帰を避け、状態を直接復旧。
- モバイル履歴は単一の復帰マーカーを使い、手動で閉じた際に `history.back()` によって別ページへ移動する事故を防止。
- カスタム選択メニューも最前面レイヤーとして扱い、Esc／Tab／戻る操作／診断対象に追加。
- メニューのフォーカス復帰先はクリック元を保持し、開いた直後のフォーカス再同期でボタン参照が失われないよう修正。

## 操作性・スマホ対応
- Tabキーのフォーカス循環、開いた直後のフォーカス移動、閉じた後のフォーカス復帰を追加。
- ソフトウェアキーボード、画面回転、ノッチ・ホームインジケータを考慮したウィンドウ寸法補正を追加。
- スマホ設定パネルの委譲イベントで実際の閉じるボタンIDを認識するよう修正。
- 設定パネルの `aria-expanded`／`aria-hidden` を開閉状態と同期。
- 既知のbody状態クラスが閉鎖後に残った場合の復旧処理を追加。

## 診断・保全
- 端末診断にウィンドウ要素、閉じる操作、dialog構造、タイトル、重複ID、スマホ戻る、フォーカス管理を追加。
- Service Workerキャッシュをv44へ更新し、新規管理JS/CSSをオフライン必須ファイルへ登録。
- 描画エンジン、ブラシ計算、作品データ構造、IndexedDBスキーマ、PSD入出力には変更を加えない。
- 220項目のウィンドウ／PC／スマホ／データ保全／回帰監査リストを追加（220個の新規描画ツールという意味ではなく、確認すべき監査チェックポイント数）。

## 確認範囲と制限
- ソース静的検査ではHTML ID重複なし、ローカル参照先欠落なし、ARIA／label参照先欠落なし、JS/CSS構文エラーなしを確認。
- 実ブラウザーでのクリック／タッチ動作は別途確認が必要です。

## 操作方法
- 最前面ウィンドウ：`Esc`
- PCの代替ショートカット：`Alt+Shift+W`
- スマホ：ウィンドウ表示中にブラウザー／端末の戻る操作
- API：`window.PF_WINDOW_MANAGER.closeTop()`／`closeAll()`／`audit()`
