# PIXEL FORGE STUDIO v44.0 検査記録

## この環境で実施した検査
- JavaScript 21ファイルとService Worker `sw.js` のNode構文検査（全件通過）。
- 新規ウィンドウ管理モジュール、アプリ本体、スマホUI、カスタム選択メニューの構文検査。
- HTMLのID 566件に重複なし、ローカル参照先に欠落なし、ARIA参照先に欠落なし、label参照先に欠落なし。
- CSS 18ファイルのパーサー構文検査（エラーなし）。
- Web App ManifestのJSON検証、Service Worker参照先105件の存在確認（欠落なし）。
- 220項目の回帰監査チェックリストの件数確認。
- ウィンドウ監視が `aria-hidden` を監視していないこと、属性値の変更がある場合だけ書き込むことを確認。
- Service Workerのキャッシュ登録・新バージョン名・参照ファイルの検査。
- ZIP作成後の整合性検査とファイル一覧の検査。

## この環境で実行できなかった検査
- Chromiumによるローカルページの起動・実操作検証は、この実行環境では完了できませんでした。
- そのため、実際のクリック、Esc、Android／iOS戻る操作、タッチ、フォーカス循環、描画、PSD、作品保存のE2E確認は未実施です。
- これらを実機で合格したとは記録していません。

## 重要な修正内容
- 新しいキャンバスに閉じる×／背景クリック／Escを追加。
- モーダルと動的ウィンドウの閉じる管理を統一。
- スマホ戻る操作の履歴連携。
- スマホ設定パネルのボタンID不一致修正。
- ウィンドウ監視の `aria-hidden` 自己更新ループを防止。
- スマホ設定パネルの合成クリックによる再帰クローズを排除。
- カスタム選択メニューの閉鎖優先順位と、メニュー開閉の単一履歴マーカーを追加。
- VisualViewport・セーフエリア対応、フォーカス管理、状態クラスの復旧。
- ウィンドウ監査結果を端末診断へ追加。

## 追加の注意
220項目は監査チェックポイントです。220個の新規描画ツール／機能を追加したという意味ではありません。今回の追加はウィンドウ管理・スマホ復旧・アクセシビリティ・診断に限定しています。

## データ保全上の範囲
描画・レイヤー・ヒストリー・保存形式・PSD処理のロジックは今回変更していません。これは「回帰試験に合格した」ことを意味しません。作品を保持したテスト用コピーで、保存・読込・PSD・スマホ描画を再確認してください。
