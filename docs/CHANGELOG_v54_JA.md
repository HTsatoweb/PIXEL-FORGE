# PIXEL FORGE STUDIO v54.0 変更履歴

## スマホ版：操作の再設計
- 下部ナビを7項目へ再構成し、「戻す」「やり直し」を常時表示。
- 履歴の有無を編集エンジンの状態と同期し、使用できない操作は無効表示。
- 履歴ボタン長押しで連続Undo/Redo。短いタップは1回だけ実行。
- ツール／ブラシ／カラー／レイヤー／その他をワンタップで切替。
- タップ処理を専用ルーターへまとめ、旧バブルフェーズの重複ルーターを通さないよう変更。
- 設定ドロワーにフォーカス制御、Escape、ブラウザー戻る／進む、見出し右スワイプによる閉じる操作を追加。画面幅がPCへ切り替わった場合はモバイル用履歴状態も後片付けします。
- ボタン最小サイズ、セーフエリア、押下状態、無効状態を再調整。
- スマホの固定「UI整理」ボタンを非表示にし、ホームヘッダーと「その他」内へショートカットを移動。

## PC版：作業導線の改善
- 小画面PCの上部メニューとツールボタンの幅を調整。
- 左ツール列・右設定パネルを独立スクロール可能にし、キャンバスを押しつぶしにくく変更。
- 低い画面高でヘッダーとツール列の高さを圧縮。
- キーボードショートカット、既存のPCツール、UI整理機能は維持。

## 既存機能・データ
- 描画エンジン、画材、ブラシプリセット、紙質、レイヤー、変形、PSD互換、作品ライブラリ、PForge保存データの形式変更なし。
- 旧バージョンのMarkdown資料と変更履歴は削除していません。
- 背景色・背景画像・テーマの基調は変更していません。

## バージョン
- アプリ本体：54.0.0
- Service Worker cache：pixel-forge-v54
