# PIXEL FORGE STUDIO v47.0 変更履歴

## 重大修正：設定パネルが閉じられない

- `syncResponsiveLayout()`がデスクトップ幅で毎回`rightbar.collapsed`を削除していた問題を修正。閉じる操作でパネルが非表示になるとキャンバス領域が拡大し、ResizeObserver経由で同関数が再実行されてパネルを再表示していました。今はデスクトップでユーザーの開閉状態を保持します。
- `PF_EDITOR_ACTIONS.panel()`がPCで常に「開く」方向へ動いてしまう判定を修正し、PCでも開閉トグルとして機能します。
- 検索ツールバーの「閉じる ×」を合成クリック方式から直接状態更新方式に変更。スマホの×ボタンやEsc処理との再帰・競合を避けます。
- 閉じるときに`collapsed`、`mobile-panel-open`、`aria-hidden`、`aria-expanded`、スクリーン状態、モバイル設定の保存値を同期します。

## モバイルUIの重なり修正

- モバイル設定パネルのDOM順を「ヘッダー → 検索／一括操作ツールバー → カテゴリータブ → ツール／操作グリッド → 設定パネル」に整理。
- カテゴリータブのsticky位置とツールバーのsticky位置が重なる問題を修正。カテゴリータブは本文と一緒にスクロールします。
- 画面幅360px以下では「閉じる ×」を操作列の下段いっぱいに配置。タップ領域を44px以上確保します。
- 閉じるボタンの視認性・フォーカス表示を強化。検索欄の×は「検索文字を消去」と明示し、パネルを閉じる操作と区別します。

## 維持した機能・互換性

- カラー選択・色検索・パレットカテゴリ、ブラシ設定・プリセット、設定検索、全て開く／全て閉じるを維持。
- 8種類の制作モード、ツール、レイヤー、アニメーション、描画・消しゴム・混色機能を削除していません。
- `.pforge` version 5、IndexedDB `PixelForgeDB` schema version 3を維持。
- 既存ファイルを削除せず、UI制御・CSS・説明資料のみを更新。
