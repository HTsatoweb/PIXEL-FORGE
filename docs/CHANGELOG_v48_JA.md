# PIXEL FORGE STUDIO v48.0 変更履歴

## 追加概要

ホーム・エディタ・既存機能の連携を、検索可能な「強化センター」にまとめました。合計 **350件の実行項目** を追加しています。

| 領域 | 項目数 | 内容 |
|---|---:|---|
| ホーム | 100 | 作品一覧、表示レイアウト、絞り込み、並べ替え、複数選択、バックアップ、ナビゲーション、外観、アクセシビリティ |
| エディタ | 200 | ツール20、ブラシプリセット20、カラー20、サイズ20、不透明度20、レイヤー20、ズーム20、紙質20、アニメーション20、入出力20 |
| 連携・細部UI | 50 | ファイル形式、設定同期、入力支援、PWA／キャッシュ、診断、ワークフロー連携 |

## 強化センター

- ホーム／エディタ／連携・UIの3タブ。
- 日本語の全文検索、カテゴリ絞り込み、24項目ずつのページ送り。
- 項目ごとのお気に入り、最近使った機能の記録。
- PC上部バーとホームのPC／モバイル操作列に入口を追加。
- `Ctrl + Shift + P`（macOSでは `⌘ + Shift + P`）で開閉。
- 閉じるボタン、背景タップ、Esc、ウィンドウ管理との連携。

## ホーム強化

- 10種類のカード表示レイアウト。
- お気に入り、最近編集、キャンバス比率、サイズ、旧版データによるスマート絞り込み。
- 作成日・編集日・名前・幅・面積・お気に入りによる並べ替え。
- 表示中全選択、反転、最近の作品、お気に入り、旧版、先頭N件などの一括選択。
- 作品検索ショートカット、アーカイブ、設定バックアップ、端末診断、PWA案内への導線。
- お気に入り状態、ホームレイアウト、絞り込み・並び替えを端末内に保存。

## エディタ強化

- 既存20種類のツールを呼び出すショートカット。
- 実際に存在するブラシプリセット・紙質オプションから各20項目を登録。
- クイックカラー20色、ブラシサイズ20段階、不透明度20段階。
- 既存レイヤーAPIを使う20種類のレイヤー操作。
- ズーム20段階、アニメーション20項目、ファイル入出力20項目。
- 既存の描画ツール、レイヤーエンジン、フレーム処理、PSD／OpenRaster／画像入出力を置き換えずに接続。

## 連携・細部UI

- プロジェクト・PSD・画像・PNG・JPG・WebP・OpenRaster・アーカイブの既存操作へ接続。
- テーマ、UI倍率、ホーム密度、タッチターゲット設定をアプリ標準設定で保存。
- タッチ領域、動きを減らす、高コントラスト、読みやすさ、フォーカス表示、左手向けレイアウト。
- オフラインキャッシュ、端末診断、設定バックアップ、ヘルプ、コマンドパレットへの導線。

## 既存機能の保全

- v47.0に含まれる元ファイルは削除せず保持。
- 新規コードは `js/forge-enhancement-suite-v48.js` と `css/forge-enhancement-suite-v48.css` の2ファイル。
- `.pforge` のバージョン、IndexedDBのスキーマ、既存の描画・ブラシ・PSD・レイヤー・アニメーションコードを変更しない。
- Service Workerのキャッシュ名を `pixel-forge-v48` に更新し、新規コードをキャッシュ対象に追加。

## 項目数について

350件は、既存機能を呼び出す実行項目・設定プリセット・表示補助の件数です。350種類の新規描画エンジンや新しい高度フィルターを意味しません。既存機能に存在しない動作を架空に追加せず、APIやDOMコントロールに接続する方式です。
