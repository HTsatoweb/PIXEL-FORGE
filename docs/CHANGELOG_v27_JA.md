# PIXEL FORGE STUDIO v27.0 — 修正履歴

## 保存・作品ライブラリ
- ライブラリ保存に失敗しても、`.pforge` の外部バックアップ出力を継続するように修正。
- IndexedDBへの保存後に読み戻し確認を追加し、保存成功の誤表示を防止。
- 保存処理を直列化し、手動保存と自動保存が同時に書き込む競合を抑制。
- 保存中に編集が続いた場合、作品を誤って「保存済み」にしないよう更新時刻を比較。
- サムネイル生成に失敗しても作品本体の保存を継続。
- ダウンロード名を安全化し、モバイル端末向けに Blob URL の解放を遅延。

## ホーム・操作
- ホーム画面のデスクトップボタンに二重登録されていたイベントを整理し、PC／スマホとも委譲イベント1本に統一。
- PC用ホーム操作ボタンに不足していたアクション属性を追加し、デスクトップ側も再接続。
- 保存中に別編集が行われた場合、保存開始時の更新時刻を基準に再度自動保存するよう修正。
- ファイル保存ピッカーの非同期キャンセル・失敗を即時捕捉し、未処理Promiseを防止。
- ホーム操作のフォールバックで再帰クリックが起きないようガードを追加。
- ホームボタンは保存待ちの前に画面を切り替え、複数レイヤー作品でも反応が止まったように見えないよう改善。
- UI設定の保存・復元対象だった左ツールバーに `leftbar` IDを追加。
- 全ボタン・カード・画面遷移に軽量モーションを追加。描画キャンバスやポインター描画処理には介入しない。
- OS／アプリの「動きを減らす」設定を尊重。

## 配布・キャッシュ
- Service Workerのキャッシュ名をv27へ更新し、古いv26キャッシュが修正版を上書きし続けないよう変更。
- 既存の描画エンジン、PSD互換、ブラシ、Worker、アニメーション機能、レイヤー、書き出し機能は保持。
