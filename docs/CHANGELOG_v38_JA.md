# PIXEL FORGE STUDIO v38.0 変更履歴

## 8つの専用ワークスペース

ホームから選ぶ「はじめて・イラスト・アナログ画材・写真加工・デザイン・ピクセルアート・アニメーション・上級者」の各モードに専用ワークベンチを追加。モード別の操作バー、制作手順、画材・編集・書き出しのクイック操作を配置しました。エディター内のモード切替、ホームへの戻り、右側パネルの表示/展開にも対応します。

## ピクセルアート専用描画

- ピクセルモード中の入力座標を整数セルに固定。
- Bresenham方式の連続ピクセル線。
- 硬いピクセル消しゴム。
- ピクセル単位の直線・長方形・楕円（輪郭/塗り）。
- アンチエイリアスを切ったキャンバス表示。
- ズームに応じたピクセルグリッド。
- PICO-8 / Game Boy / DB16 / 暖色 / 寒色 / Pastel パレット、色の追加。
- PNGを1× / 2× / 4× / 8×で出力する選択欄。ピクセルモードでは拡大時の補間を無効にし、輪郭をぼかさずに出力。

## 画材プロファイル

既存ブラシの選択時、まだユーザー保存済みのプロファイルがない場合に80種類の標準画材プロファイルを適用します。Gペン、丸ペン、ミリペン、万年筆、筆ペン、透明水彩、にじみ水彩、墨、油彩、アクリル、ガッシュ、鉛筆、木炭、チョーク、パステル、マーカー、エアブラシ、金属顔料、テクスチャ筆などに対し、筆先形状・縦横比・筆圧・入り抜き・硬さ・流量・水分・顔料・毛束・紙質の初期値を分けています。ユーザーが保存済みのブラシプロファイルは上書きしません。

## UI/安定性

- 各モードの専用ワークベンチを追加。狭い画面で折り返すレイアウトを追加。
- モード切替の監視属性を正しいHTML属性名へ修正。
- パネルをIDなしでも開けるように修正。
- ピクセル図形のプレビューもピクセル描画に統一。
- サービスワーカーのキャッシュ名をv38.0へ更新。
- 既存のIndexedDB名/バージョン、プロジェクト形式、基本描画処理の保存データ構造を変更しない。

## 大事な実装範囲

80種類の画材プロファイルは既存の2Dブラシエンジンが持つ筆圧・リボン形状・毛束・紙目・水分・顔料のパラメーターを使う画材モデルです。実物の毛一本一本や流体を完全に物理シミュレーションするものではありません。AIを利用する機能は追加していません。構想にある500以上の全機能が完成したという意味ではなく、実動作するモード専用UI・ピクセルエンジン・画材設定を優先して追加した更新です。
