# PIXEL FORGE STUDIO v44.0 — 220項目の強化・回帰監査チェックリスト

この一覧は、ウィンドウ閉鎖不能の修正を中心に、PC・スマホ・データ保全・描画回帰・PWAまで確認範囲を広げるための**220項目の監査チェックポイント**です。チェックポイントは機能追加数そのものではありません。項目のうち、コード上で導入・静的確認できるものと、ブラウザー／実機で操作して合否を確定するものを区別してください。

## 実装済みの中心的な修正
- 共通ウィンドウ管理（最前面判定、Esc、背景クリック、閉じるボタン、一括クローズAPI）
- スマホの戻る操作をウィンドウ／設定パネルに連携
- フォーカス初期化・Tab循環・閉じた後のフォーカス復帰
- VisualViewportとセーフエリアを考慮した高さ・幅補正
- スマホ設定パネルの閉じるボタンID不一致修正とARIA同期
- 診断画面にウィンドウ構造・閉じる操作・重複ID監査を追加

## 判定の読み方
- `[x]`：ソース／構文／参照先など、今回の作業環境で静的に確認できた項目。
- `[ ]`：実ブラウザー・実機での手動またはE2E確認が必要な項目。
- 未実施項目を「合格」とは扱いません。作品保存や描画エンジンは変更していませんが、回帰試験が不要という意味ではありません。
