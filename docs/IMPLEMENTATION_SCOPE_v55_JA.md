# PIXEL FORGE STUDIO v55.0 実装範囲と残件

## 方針

v55.0はv54.0の編集エンジンを置き換えず、既存の `PF_STUDIO_API` を通じて追加UIを接続する拡張版です。既存ファイルを削除せず、`.pforge` version 5 と `PixelForgeDB` schema version 3 を維持しています。

## v55.0で実際に追加したもの

- **強化ツールセンター**：ホーム（PC/スマホ）とエディターから開ける追加パネル。Alt+Shift+Fにも対応。
- **レイヤー操作**：追加、複製、選択、表示/非表示、不透明度、名前変更。既存APIの履歴経路を利用。
- **色管理**：HSL配色候補、最近使った色、お気に入り、作品合成画像からの代表色抽出、JSONパレット入出力、白/黒とのコントラスト比。
- **表示・キャンバス**：25/50/100/200/400%表示、全体表示、実ピクセル表示、中央基準のキャンバス拡張（最大20MP）。キャンバス拡張は既存エンジン仕様によりUndo/Redo履歴がリセットされるため、確認ダイアログで事前警告。
- **保存・診断**：現在作品の `.pforge` 書き出し、既存の全作品 `.pfarchive` バックアップ、ブラウザー容量推定、既存描画回帰テストへの入口。
- **ファイル検査**：画像/PSD/JSONファイルの容量、先頭シグネチャ、形式を既存インポート処理の前に確認。画像デコードは20MPを上限にする。
- **読み込み先制限**：ファイルからのSVG直接読込を拒否し、`.pforge` 内のSVG data URIと外部オリジン画像参照も拒否。
- **配信保護**：CSPとローカルサーバーHTTPセキュリティヘッダーを追加。

## 600項目一覧に対する実装状態

この版は600項目すべての完了版ではありません。v55.0では既存APIだけで競合リスクを抑えて追加できる範囲を先行実装しています。元の600項目一覧は `ENHANCEMENT_IDEAS_600_JA.md` に同梱しています。

### まだこの版では実装していない大きな領域

- 水彩の乾燥/顔料移動/バックラン、油彩の厚みなどの高度な物理画材エンジン改良。
- 非破壊レイヤーマスク、クリッピング、調整レイヤー、複雑なレイヤー効果。
- 編集可能なベクターオブジェクト、ベジェ節点編集、高度なテキスト組版。
- 写真フィルター群、トーンカーブ、色域選択、背景除去の高度化。
- フレーム補間、音声同期、GIF/WebM書き出しの追加機能。
- 端末別の筆圧/傾き/ペンサイドボタンの実機検証と詳細設定。
- PSDの完全互換、完全な自動回復や巨大作品での全経路パフォーマンス保証。

上記は単にボタンを増やすだけでは安全に実装できません。専用データ構造、Undo/Redo、保存形式移行、モバイル/PC回帰テストを整えてから段階的に追加する必要があります。

## セキュリティ上の限界

- 既存のインラインコードを維持するため、CSPの `script-src` と `style-src` に `unsafe-inline` が残っています。外部オリジンのスクリプト/通信は許可しませんが、nonce/hashだけの厳格CSPではありません。
- `.pforge` / `.pfarchive` / 設定ファイルの構造検査は既存ローダー側でも行います。追加ゲートだけで不正データ全般を完全に判定できるわけではありません。
- ブラウザー内の作品データを暗号化する機能、端末のウイルス対策、外部バックアップサービスは提供しません。
- `server.py` は同一Wi-Fiのスマホから利用できるよう全ネットワークインターフェースで待ち受けます。信頼できる家庭内ネットワークでのみ使い、ポートをインターネットへ公開しないでください。

## 検証済み範囲

JavaScript/Python構文、JSON、HTML/CSS/Service Workerのローカル参照、旧版ファイル保持、保存形式/DBバージョン、ローカルサーバーのHTTPヘッダーは静的・ローカル検査済みです。ブラウザーの全画面実行は実行環境の管理者ポリシーにより遮断されたため、実機UI、タッチ、筆圧、長時間描画、PSD実ファイルのラウンドトリップは未検証です。
