# PIXEL FORGE STUDIO v34.0 変更履歴

## 主な更新

- エディタ上部のモバイル操作列を左固定・左詰めし、ブランド領域・余白・ボタン幅・順序を明示的に制御。
- 旧バージョンで保存されたヘッダー横方向オフセットが、モバイルでホーム／保存ボタンを右へ押し出さないよう横方向を固定。ボタン順序変更と縦方向の微調整は維持。
- UI配置編集の対象をホーム操作、ブラシラボ、虹色設定、タイムライン、各モーダル、画面内の残りの個別ボタン・入力欄まで拡張。重複対象はWeakSetで一度だけ登録。
- 虹色ブラシに開始位相（0〜360°）と色の流れを逆にする設定を追加。
- 曲線に沿う虹色、横虹色、縦虹色の方向別カラー補間で、位相・逆方向・下色拾いの順序を反映。
- 虹色・指先混色の設定をブラシ別プロファイルへ保存・復元し、画材プロファイルのフォーム項目重複を解消。
- 指先強度0%を初期値へ勝手に戻さないよう数値処理を修正。
- 現在のブラシ設定を別のブラシへ一括コピーする機能を追加。84個の画材フォーム項目をプロファイルに記録。
- 新規作品データに虹色位相・逆方向・指先合成参照を互換用のトップレベル項目としても保存し、旧形式の読み込み時はファイル中に値がある設定を初期化しない。
- 作品メタデータのアプリ版表示を34.0.0へ同期。
- HTMLはルート階層を維持し、JavaScriptを `js/`、CSSを `css/`、画像を `assets/images/`、Markdownを `docs/` に整理。
- Service Worker `sw.js` はルートスコープを保つためルートに残し、キャッシュ対象パスとオフライン資料一覧を新しい構成へ更新。
- IndexedDB名 `PixelForgeDB` とスキーマバージョン3を維持し、既存作品ストアを初期化・削除しない。

## ZIP構成

- `index.html` / `help.html` / `manifest.webmanifest` / 起動用スクリプトはルート直下。
- `js/` に通常のJavaScript、`css/` にスタイル、`assets/images/` に画像、`docs/` にMarkdown資料を格納。
- `sw.js` はWebアプリのルートスコープを維持するため例外的にルート直下。

## 更新時の注意

作品は同じブラウザ・同じオリジン（スキーム、ホスト、ポート）に保存されます。起動URLやポート番号を変更すると別領域に見えることがあります。更新前にホーム画面から `.pfarchive` を書き出しておくことを推奨します。
