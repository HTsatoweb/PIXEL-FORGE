# PIXEL FORGE STUDIO v32.1 変更履歴

## 最重要：作品消失・更新後の再開対策
- IndexedDB名 `PixelForgeDB` とスキーマ v3 を維持。バージョン更新で作品DBを削除・初期化しない。
- `projects` を作品本体の正本として扱い、`library` の一覧データが欠けた場合は作品本体からカード情報を再構築。
- 起動時に `autosave` ポインタから最後に保存した作品を読み戻してエディタを再開。旧形式 `autosave.data` と新形式 `autosave.projectId` の両方に対応。
- ページがバックグラウンドへ移る際と終了時に追加保存を試行（ブラウザが許可する範囲でのbest-effort）。
- 自動保存間隔の最低値を1.8秒に調整。
- 全作品を `.pfarchive` へ一括バックアップ／復元する機能を追加。別URL・別ポート・別ブラウザへの移行を支援。
- ホーム画面にも `.pfarchive` の復元・バックアップボタンを追加し、作品が見つからない場合の復旧入口を明示。
- 現在の保存先originをホームに表示。プロトコル・ホスト・ポートが違うと別保存領域になることを案内。

## UI修正・強化
- v31で保存された上部バーの移動オフセットをリセットし、スマホ上部のホーム等を強制左寄せ。
- 小型スマホ用のロゴ幅とボタン幅を再調整。
- 個々の上部ボタン、左ツール、サイズ／ズームグループ、右パネル、設定欄、レイヤー操作、下部ドックをドラッグ配置可能。
- 端末サイズ別に配置を保存。初期配置へ復元可能。
- ネオン移動ハンドルと軽量な押下・フォーカスモーション。
- v31の虹色ブラシと保存進捗表示を維持。

## 互換性・データ保護
- `.pforge` の形式は変更なし（version 5）。
- IndexedDBのDB名・バージョン・既存Storeは変更なし。
- 作品データを削除する処理は追加していない。
- Service Workerのキャッシュ名をv32.1へ更新。旧アプリシェルだけを入れ替え、IndexedDB作品には触れない。

## 重要な移行条件
同じブラウザ・同じorigin（プロトコル、ホスト、ポート）であればIndexedDBの既存作品を読み戻します。別originや別端末に以前の作品データを移すには、旧環境で事前に `.pfarchive` または `.pforge` を書き出しておく必要があります。新しいoriginから旧originのIndexedDBを自動で読むことはブラウザの仕様上できません。
