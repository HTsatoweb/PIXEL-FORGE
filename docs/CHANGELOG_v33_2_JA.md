# PIXEL FORGE STUDIO v33.2 修正履歴

## 虹色ブラシの描画を改良

- 「線に沿って流れる」モードを、始点と終点を結ぶ直線方向の色変化から、実際のストローク中心線の移動距離に沿って色が変わる方式へ変更しました。
- カーブ・折り返し・曲線のあるストロークでも虹色が順番に移り変わります。
- 横虹色（左→右）と縦虹色（上→下）は独立した方向グラデーションとして維持しています。
- 下色拾いの設定と混色率は、新しい曲線描画にも適用されます。

## 虹色と指先混色

- 指先混色がストローク開始時のレイヤーを対象にするよう変更し、描画中にアクティブレイヤーが変わった場合の履歴記録先のずれを防ぎます。
- 「指先混色：表示中のレイヤー全体を参照」を追加しました。ONにすると、表示中のレイヤーを合成した色を拾って、選択中のレイヤーへ混ぜ伸ばせます。
- 虹色ラボの「指先・混色で虹色を伸ばす」ボタンは、表示レイヤー全体の参照を自動でONにしてから指先ツールへ切り替えます。
- この参照モードは少し処理負荷が高くなるため、チェックでOFFにもできます。
- 設定は作品・ブラシプロファイルに保存され、読み込み時に復元されます。

## モバイルUIと細かな配置編集

- 旧UI編集スクリプトと新UI編集スクリプトが同じ編集モードを二重に起動しないよう、詳細配置編集の操作入口をv32側に一本化しました。
- 旧スマホUI編集時の36〜38pxの予約余白を解消し、編集モードでホーム・保存ボタン列やツールバーが横へ押される原因を除去しました。
- ホーム画面とエディタ画面の上部バーを物理的な左端から並べ、余白が操作ボタンを右へ押し出さない構造にしています。
- 旧バージョンで保存されたブランド／ヘッダーの位置オフセットは一度だけ移行時にクリアし、新しいv3配置データは保持します。
- UI移動ハンドルを対象要素の子ではなく画面上の固定レイヤーへ配置。input・select・textareaの中へ子要素を誤挿入する問題を防ぎます。
- 折りたたみパネルや設定ダイアログを開いたときも、表示されたUIに移動ハンドルを追加します。
- 旧版のトップバー強制スタイルを除去し、デスクトップレイアウトへ不要なインライン指定を残さないようにしました。
- v31の保存済みボタン順序は可能な範囲で維持します。

## 維持した機能

- 作品データベース `PixelForgeDB`、作品・レイヤー・フレーム・自動保存・`.pforge`・`.pfarchive` の既存データ構造は初期化しません。
- 既存の保存進捗表示、ホーム移動前のバックアップ保護、作品一覧再構築、全作品アーカイブ復元を維持しています。
- オフラインキャッシュ無効化設定とCache Storage管理の仕組みを維持しています。作品データベースはキャッシュ削除対象ではありません。

## 注意

IndexedDBはブラウザのorigin（スキーム・ホスト・ポート）ごとに分かれます。更新後も従来と同じURL・同じブラウザで起動してください。別URL・別端末へ移す場合は、旧環境から`.pfarchive`または`.pforge`を先に書き出してください。すでに消去されたブラウザデータや、旧URL側に残っていてアクセスできないデータを新バージョンだけで復元することはできません。
