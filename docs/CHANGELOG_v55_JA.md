# PIXEL FORGE STUDIO v55.0 変更履歴

## 強化ツールセンター
- ホーム（PC/スマホ）とエディターの入口から「FORGE CONTROL CENTER」を開けるようにしました。`Alt + Shift + F`でも表示できます。
- 作品寸法・レイヤー数・ズーム・Undo/Redoの状態を一覧表示します。
- 既存APIを使用したレイヤー選択、表示/非表示、不透明度、名前変更、複製、新規作成を追加しました。
- 色相の配色候補、最近使った色、お気に入りパレット、作品画像からの代表色抽出、JSONパレット入出力、白/黒とのコントラスト比表示を追加しました。
- 25/50/100/200/400%の表示倍率、全体表示、実ピクセル表示、キャンバス中央基準の拡張を追加しました。
- 現在の作品を既存 `.pforge` version 5 形式で書き出す機能、全作品 `.pfarchive` バックアップへのショートカット、保存容量推定、既存の描画回帰テスト実行を追加しました。

## セキュリティ・データ保護
- CSPを追加し、スクリプト・スタイル・画像・通信の取得元を同一オリジン中心に制限。外部オブジェクト埋め込み、外部フォーム送信、外部接続を禁止します。
- 既存インポート処理が動く前に画像/PSD/JSONの容量と先頭データを検査するゲートを追加しました。画像は対応ラスター形式のマジックバイト、PSDは `8BPS`、JSON系はテキスト先頭を確認します。
- 大きすぎる画像・PSD・設定ファイルを事前に拒否し、画像はブラウザーが対応する場合に20MPの寸法上限も検査します。
- SVGファイルの直接読み込みを制限します。外部スクリプト/参照が含まれる可能性を避けるため、PNG/WebP等へ変換して読み込んでください。
- `.pforge`内の画像参照はSVGを除くdata画像または同一オリジン参照に限定し、外部サイトの画像URLを開くことで第三者へ接続する挙動を防ぎます。
- ローカルサーバーを `server.py` 方式へ変更し、CSP、`X-Content-Type-Options`、`Referrer-Policy`、`Permissions-Policy`、`X-Frame-Options` をHTTPレスポンスに付与します。

## 互換性
- `.pforge` version 5、`PixelForgeDB` schema version 3、既存の作品・履歴・ブラシ・画材・アニメーション・PSD/ORA処理の形式は変更していません。
- v54のCSS/JSファイルやUIルーターは削除せず、追加モジュールとして統合しています。
- レイヤー不透明度スライダーはドラッグ中にプレビューし、確定時に元の値から1回のUndo履歴として記録します。
