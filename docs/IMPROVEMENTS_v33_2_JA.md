# v33.2 改善内容

1. 虹色「線沿い」を曲線の弧長ベースに変更。
2. 曲線・折り返しで色相が止まらないよう局所グラデーションで描画。
3. 横方向虹色と縦方向虹色は別モードとして維持。
4. 虹色の下色拾いを曲線上のサンプル位置に沿って混合。
5. 指先混色の対象レイヤーをストローク開始時に固定。
6. 表示レイヤー合成色を参照する指先混色オプションを追加。
7. 虹色ラボからの指先ボタンで合成色参照を自動有効化。
8. 合成指先設定を作品・ブラシ設定へ保存。
9. スマホのホーム／エディタ上部バーの左寄せを一本化。
10. 旧配置CSSの余分な左・上パディングを削減。
11. v31とv32の配置編集イベント二重登録を解消。
12. input/select/textareaにも使える浮動移動ハンドル。
13. 折りたたみ・表示切替後のUIにもハンドルを追従。
14. 古いヘッダー位置データを一度だけ安全に移行。
15. デスクトップ時にモバイル専用のインラインスタイルを解除。
16. 保存進捗・自動保存・作品バックアップ・アーカイブを維持。
17. Cache Storageの削除機能と作品IndexedDBを分離したまま維持。
18. 既存HTML ID・既存作品保存形式を維持。

これらは変更内容の一覧であり、実機で18項目すべてを操作テストしたという意味ではありません。実施できた検査と未確認項目は`TEST_RESULTS_v33_2_JA.md`を参照してください。
