# v35.0 改善内容

## 動きの一貫性

- 全ボタンのhover / active / pointer / keyboard表現を共通化。
- 設定・ダイアログ・コマンドウィンドウの入場に異なるイージングと奥行き感を追加。
- パネル、ヘッダー、モバイルドック、配置編集対象の位置差分を最大190要素まで監視。
- 加算型transformで既存の位置・変形と重ねてアニメーションし、描画キャンバスそのものには装飾演出を適用しない。
- 端末回転・画面リサイズは移動アニメーションの対象から短時間除外し、レスポンシブレイアウトの揺れを防止。

## 精密微調整

- 合計350スライダー、35の実パラメーター、7カテゴリ。
- 各スライダーの中立値は50。各項目は対象パラメーターの全範囲の最大±1.8%を補正し、10項目合計でも範囲外へ出ないよう制限。
- 1フレーム内の連続変更はrequestAnimationFrameでまとめ、元の設定欄へinputイベントを1回だけ送る。
- 自動保存は320msのデバウンス。設定ファイルの読み込みは形式・スキーマ・数値・項目数を検証してから反映。

## 安全なデータ更新

- 作品データ用IndexedDBを変更せず、新規の設定キーのみを使用。
- 既存のブラシプロファイル・作品保存・レイヤー履歴・書き出し処理を削除しない。
