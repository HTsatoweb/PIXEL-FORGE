# PIXEL FORGE STUDIO v41.0 変更履歴

## 全体UIレイアウトスタジオ
- ホームとエディターのUIを横断して、UIパーツ単位で個別に非表示・再表示できる設定画面を追加。
- 直接整理モードでは、対象UIに触れるとその位置に「×」を表示。クリック操作は整理モード中のみ抑止され、誤操作を防止。
- UI整理メニューから表示／非表示の切替、検索、非表示項目の復帰が可能。
- PCとスマートフォンのレイアウト設定・表示状態を独立保存。片方で隠しても他方には影響しない。
- エディターの表示状態は8つの制作モードごとに保存。
- ホームのモードカード、検索、バックアップ、作品一覧、各ホーム操作を個別に整理可能。
- エディターの上部バー、左ツール、コンテキスト設定、モバイル操作、ステータス、右側の各設定パネルを個別に整理可能。
- フレックス／グリッド内の対象UIは上下移動による並び替えに対応。
- すっきり／集中／標準プリセットを追加。非表示は削除ではなく、いつでも復帰可能。

## 見た目・操作感
- UI密度、全体スケール、右パネル幅、ツールサイズ、パネル間隔、角丸、ホームカード列数、パネル位置を調整可能。
- アニメーション、ツールチップ、上部ラベル、コンテキストバー密度を個別設定可能。
- PCでは右側の設定幅を調節、スマートフォンでは全画面の整理シートと安全領域対応。
- 画面上に常設の「UI整理」入口を追加。

## 独立設定数について
- 実際に検出したUIパーツ数を基に、PC／スマホ別・8モード別の独立表示設定スロット数をUIに表示する。
- 静的ホーム／エディターHTMLを用いたDOM検査では1,278スロットを確認（モード別の動的パネルを含む最終数は実行時に算出）。
- これはUIの表示・配置を個別に保存する設定数であり、500種類の新しい描画エンジン／画材機能を意味しない。

## 互換性・保護
- 作品データ、レイヤー、描画履歴、既存のブラシ処理、IndexedDB schemaには変更を加えない。
- UI設定は専用localStorageキー `pf-ui-layout-studio-v41` に保存。
- v40のワークベンチ内個別非表示機能も維持し、全体UI整理メニューから復帰操作を提供。
- Service Workerキャッシュをv41へ更新。
