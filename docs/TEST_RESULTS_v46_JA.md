## 未確認・制限

隔離ハーネスはopaque originのため、IndexedDB APIがブラウザーに拒否されました。これはアプリの通常オリジンでの保存失敗を示すものではありませんが、**IndexedDBへの実保存・再読込が成功したとは判定していません**。ローカルサーバーで起動した実環境での再確認が必要です。

以下は未確認です。

- Windows／macOSの通常オリジンでのIndexedDB保存・読込・クラッシュ復旧
- iOS Safari／Android Chrome実機での戻る履歴、タッチ、ソフトウェアキーボード
- 大容量作品のピークメモリ・保存時間・読み込み時間ベンチマーク
- PSD全派生形式の入出力互換性
- 外部ペンタブレット、色管理、印刷出力

## 互換性・保全方針

- `.pforge`の`PIXEL_FORGE_PROJECT` version 5を維持。
- IndexedDBの`PixelForgeDB` schema version 3を維持。
- 元の119ファイルは削除していません。
- 既存の描画・ブラシ・モード・レイヤー・アニメーション・PSD関連モジュールは保持しています。
- 旧版ファイルは履歴目的で残しています。現行HTMLから読み込むファイルはマニフェストで確認できます。
