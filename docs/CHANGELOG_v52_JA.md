# PIXEL FORGE STUDIO v52.0 — 安定化アップデート

## 修正
- `Ctrl/⌘ + K` をコマンドパレット専用に統一。設定検索は `Ctrl/⌘ + Alt + K` に分離し、同じキー操作で2つのUIが同時に開く競合を解消。
- 設定検索ショートカットは入力欄・テキスト編集欄にフォーカス中は発火しないよう変更。
- スマホ設定パネルの閉じた状態をCSSでも明示し、閉じたパネルがタップを受けたり、開閉状態が一瞬混ざったりすることを防止。
- スマホの閉じるボタン・パネル切替ボタンのタッチ操作を安定化。
- 小型PCの横幅・低い画面高で、ツールバーと設定領域が縮まず重なる問題を抑制。
- 背景色、キャンバス色、既存の描画・保存・PSD・レイヤー・アニメーション機能は変更・削除していません。

## 整理
- v50以前のバージョン固有Markdown履歴を削除。共通ガイドとv51/v52の現行資料は保持。
- Service Workerキャッシュをv52へ更新し、旧キャッシュとの混在を防止。
